เข้าสู่ระบบ & บัญชีผู้ใช้

หน้าเข้าสู่ระบบ

ฝั่งซ้ายแสดงสถานะระบบ (● ระบบพร้อมใช้งาน พร้อมเลขเวอร์ชัน) ปุ่มวิดีโอแนะนำ และจำนวนโมดูล/หมวดงานของระบบ ฝั่งขวาคือการ์ดเข้าสู่ระบบ ซึ่งทักทายตามช่วงเวลา (สวัสดีตอนเช้า / บ่าย / เย็น) ข้าง ๆ เป็นภาพท้องฟ้าที่ดวงอาทิตย์ (06:00–18:00) หรือดวงจันทร์ (18:00–06:00) เคลื่อนตามเวลาจริง ชี้เมาส์เพื่อดูว่าอีกกี่นาทีพระอาทิตย์ขึ้น/ตก มุมขวาบนมีวันที่-เวลา ปุ่ม มีอะไรใหม่ (ดูรายการปรับแก้ของเวอร์ชันล่าสุดได้โดยไม่ต้องเข้าสู่ระบบ · ปุ่มเรืองแสง มีลำโพง 📢 สั่นและป้าย NEW เมื่อมีเวอร์ชันใหม่ที่ยังไม่เคยเปิดดู) และ คู่มือ — หน้าเดียวจบไม่ต้องเลื่อน ทั้งคอมพิวเตอร์ iPad/แท็บเล็ต และมือถือ (แนวตั้งและแนวนอน) จอที่เตี้ยระบบจะซ่อนข้อมูลรองให้อัตโนมัติ

เข้าสู่ระบบ

  1. กรอก ชื่อผู้ใช้ หรือ อีเมล และ รหัสผ่าน (กดรูปตาเพื่อดูรหัสที่พิมพ์)
  2. ติ๊ก จดจำการเข้าสู่ระบบ หากใช้เครื่องส่วนตัว — ระบบจำชื่อผู้ใช้และค้างการเข้าระบบไว้ 30 วัน (ปิดเบราว์เซอร์แล้วเปิดใหม่ก็ยังอยู่ในระบบ) ส่วนรหัสผ่านให้เบราว์เซอร์จำ (กด "บันทึกรหัสผ่าน" เมื่อเบราว์เซอร์ถาม)
  3. เครื่องที่ติ๊กจดจำไว้ ครั้งหน้าหน้า Login จะทักชื่อคุณ และถ้ามีรูปในคลังรูปหน้าแนะนำทีม ตัวการ์ตูนของคุณจะชะโงกออกมาจากข้างการ์ด (พิมพ์รหัสผ่าน = ยืนตรงหลบหลังการ์ด เหลือครึ่งหน้า "ไม่แอบดูนะ" · รหัสผิด = ส่ายหัว) · ยังไม่มีรูป = ใช้ตัวการ์ตูนแทนที่มีตัวอักษรแรกของชื่อเล่นบนเสื้อ · ไม่ใช่เครื่องของคุณ กด ไม่ใช่คุณ…? เพื่อล้างชื่อและรูปออกจากเครื่อง · เข้าระบบสำเร็จจะมีหน้าทักทายสั้น ๆ พร้อม AI พูดทักทายตามช่วงเวลา (กดเพื่อข้ามได้ เสียงพูดต่อจนจบ · ไม่อยากได้ยินเสียง กดปุ่ม 🔊 มุมขวาบนของหน้าทักทาย — จำไว้ในเบราว์เซอร์ กดอีกครั้งเพื่อเปิด)
  4. กด เข้าสู่ระบบ หรือกด Enter ระบบจะพาไปหน้าแรกที่คุณมีสิทธิ์ดู
ไม่ควรติ๊ก “จดจำการเข้าสู่ระบบ” บนเครื่องที่ใช้ร่วมกับผู้อื่น บัญชีที่ถูกปิดใช้งานจะเข้าสู่ระบบไม่ได้ · ใส่รหัสผ่านผิด 10 ครั้งติดกัน บัญชีจะถูกล็อก 15 นาที (หน้าจอแจ้งเวลาที่เหลือ) รอครบเวลาแล้วเข้าใหม่ได้ หรือขอ Admin ตั้งรหัสใหม่

ความปลอดภัยของบัญชี

  • รหัสผ่านถูกเข้ารหัสเก็บที่เซิร์ฟเวอร์ ตรวจที่เซิร์ฟเวอร์เท่านั้น เครื่องผู้ใช้ไม่ได้รับรหัสผ่านของใครเลย แม้แต่ Admin ก็ดูรหัสผ่านของผู้ใช้ไม่ได้ (ตั้งรหัสใหม่ให้ได้อย่างเดียว)
  • ไม่ได้ติ๊ก "จดจำ" — อยู่ในระบบจนปิดแท็บ/เบราว์เซอร์ (ใช้งานต่อเนื่องได้สูงสุด 7 วันโดยไม่ต้องเข้าใหม่)
  • เปลี่ยนรหัสผ่านเอง — เครื่องอื่นที่เข้าค้างไว้จะต้องเข้าสู่ระบบใหม่ เครื่องที่ใช้เปลี่ยนใช้งานต่อได้ · Admin ตั้งรหัสใหม่ให้ หรือปิดบัญชี — ทุกเครื่องของบัญชีนั้นต้องเข้าใหม่ (ระบบตรวจทุกชั่วโมงและตอนเปิดหน้าเว็บ)
  • ระบบบันทึกการเข้าสู่ระบบ การเข้าไม่สำเร็จ การตั้ง/เปลี่ยนรหัสผ่าน และการเปิดดูรหัสผ่านของ รพ. ไว้ตรวจสอบย้อนหลัง
  • บริการภายนอกทั้งหมด — แจ้งเตือนกลุ่ม Line (BMS Notify), ดึงข้อมูล รพ. จาก hcode.moph.go.th, ส่งอีเมลใบประกาศ (EmailJS), AI และอ่านออกเสียง — เรียกผ่านเซิร์ฟเวอร์ของระบบเท่านั้น เบราว์เซอร์ไม่ติดต่อบริการภายนอกเอง วิธีใช้งานและการตั้งค่าทุกอย่างเหมือนเดิม

หลังเข้าสู่ระบบแล้ว รีเฟรชหน้าเว็บก็ยังอยู่ในระบบและกลับมาหน้าเดิม ถ้าเปิดลิงก์จากการแจ้งเตือน (เช่น ลิงก์อนุมัติการลา) ระบบจะพาไปที่รายการนั้นทันทีหลังล็อกอิน

วิดีโอแนะนำระบบ

ดูภาพรวมทุกเมนูได้ก่อนเข้าสู่ระบบ ไม่ต้องมีบัญชี ความยาวประมาณ 1 นาที 32 วินาที พร้อมเสียงบรรยายภาษาไทยจาก AI (เสียงเดียวกับปุ่มอ่านออกเสียงในระบบ) เล่าแบบเป็นกันเองต่อเนื่องทุกฉาก มีเพลงพื้นหลังคลอเบา ๆ (เปิดลำโพงหรือใส่หูฟัง)

  1. ที่หน้าเข้าสู่ระบบ กด ▶ ดูวิดีโอแนะนำระบบ (การ์ดภาพตัวอย่างวิดีโอใต้หัวข้อ "บริหารทุกงานของทีม ในที่เดียว")
  2. วิดีโอเล่นทันที กดปุ่มขยายเต็มจอที่แถบควบคุมได้
  3. กด ✕, กด Esc หรือคลิกพื้นที่นอกวิดีโอเพื่อปิด

  2. กรอก Username แล้วกด ส่งคำขอ
  3. ผู้ดูแลระบบจะเห็นคำขอที่กระดิ่งแจ้งเตือน ตั้งรหัสผ่านใหม่ให้ แล้วแจ้งกลับ

เปลี่ยนรหัสผ่าน / ออกจากระบบ

กดชื่อของคุณที่มุมล่างซ้ายของแถบเมนู จะมีเมนู:

  • 🔒 เปลี่ยนรหัสผ่าน — กรอกรหัสผ่านปัจจุบัน, รหัสผ่านใหม่ (อย่างน้อย 4 ตัวอักษร และต้องไม่ซ้ำรหัสเดิม) และยืนยันรหัสผ่านใหม่ แล้วกด บันทึกรหัสผ่านใหม่ (หรือกด Enter) · กดรูปตาท้ายช่องเพื่อดูรหัสที่พิมพ์ · ระหว่างพิมพ์จะเห็นแถบความแข็งแรงของรหัส, เช็กลิสต์เงื่อนไข และแจ้งทันทีว่ารหัสยืนยันตรงกันหรือไม่
  • 🚪 ออกจากระบบ — ล้างข้อมูลการใช้งานบนเครื่อง และปิดการแจ้งเตือนแบบ Push ของเครื่องนั้น

รหัสผ่านเดาง่าย / รหัสตั้งต้น — บังคับตั้งรหัสใหม่ก่อนเข้าระบบ

ถ้ารหัสที่ใช้เข้าสู่ระบบเดาง่าย จะยังไม่เข้าระบบ การ์ดเข้าสู่ระบบจะเปลี่ยนเป็น กรุณาตั้งรหัสผ่านใหม่ ทันที รหัสที่ถือว่าเดาง่าย:

  • เลข/ตัวอักษรเรียงกัน เช่น 1234, 123456, 4321, abcd, qwerty
  • ตัวซ้ำหรือชุดซ้ำ เช่น 0000, 111111, 121212, 123123
  • รหัสยอดนิยม เช่น password, admin123, abc123 และรหัสที่เหมือนชื่อผู้ใช้

Admin ตั้งบัญชีใหม่หรือรีเซ็ตรหัสให้ จะได้รหัสตั้งต้น 123456 เสมอ ผู้ใช้จึงต้องตั้งรหัสของตัวเองตอนเข้าระบบครั้งแรก:

  • กรอก รหัสผ่านใหม่ และ ยืนยันรหัสผ่านใหม่ (อย่างน้อย 4 ตัวอักษร ไม่ซ้ำรหัสเดิม และไม่เดาง่าย) แล้วกด บันทึกรหัสใหม่และเข้าสู่ระบบ (หรือกด Enter) — ไม่ต้องกรอกรหัสเดิมซ้ำ
  • กด ยกเลิก กลับไปหน้าเข้าสู่ระบบ ได้ แต่เข้าด้วยรหัสเดิมเมื่อไรก็จะขึ้นหน้านี้อีก · ปิดแท็บหรือรีเฟรชระหว่างนี้ = ต้องเข้าสู่ระบบใหม่
  • เปลี่ยนรหัสเองจากเมนู 🔒 เปลี่ยนรหัสผ่าน ก็ตั้งรหัสเดาง่ายไม่ได้เช่นกัน
  • เพราะเปลี่ยนก่อนเข้าระบบ Chrome จะเห็นเป็นการตั้งรหัสใหม่และถามให้บันทึกรหัสใหม่แทน ไม่เด้งหน้าต่าง "ตรวจสอบรหัสผ่านที่บันทึกไว้" ของรหัสเดาง่าย

แถบเมนูซ้าย

เมนูแบ่งเป็นหมวด Workspace, ต้นทุน, ทีม, ศูนย์ช่วยเหลือ, ข้อมูลอ้างอิง และ ระบบ เมนูที่ไม่มีสิทธิ์ดูจะถูกซ่อนไว้ ตัวเลขสีแดงข้างเมนูคือจำนวนรายการที่รอคุณจัดการ เช่น Advance เกินกำหนด หรือการลาที่รออนุมัติ

ปุ่ม ‹ ที่ขอบแถบเมนูใช้ย่อแถบให้เหลือแต่ไอคอน ใต้ชื่อระบบมีเลขเวอร์ชันที่ใช้อยู่ (เช่น V1.006)

รูปแบบที่ใช้ร่วมกันทุกหน้า

  • ตัวกรอง — ส่วนใหญ่มี ค้นหา, ปี พ.ศ., กลุ่ม/ประเภทโครงการ (เลือกได้หลายค่า) ค่าที่เลือกมีผลกับทั้งหน้า
  • ช่องเลือก (ดรอปดาวน์) — กดแล้วเปิดแผงตัวเลือกใต้ช่อง หน้าตาเดียวกันทุกเครื่อง ค่าที่เลือกอยู่มีเครื่องหมาย ✓ · ตัวเลือกเกิน 8 รายการมีช่องค้นหาด้านบน · ใช้คีย์บอร์ดได้ (↑ ↓ เลื่อน, Enter เลือก, Esc ปิด) · บนมือถือเปิดเป็นแผ่นเลื่อนขึ้นจากด้านล่าง
  • ช่องเลือกพนักงาน/โครงการ/แผนก — พิมพ์บางส่วนของชื่อเพื่อค้นหาได้ทันที
  • ปุ่ม Excel — ส่งออกข้อมูลตามตัวกรองที่เลือกไว้เป็นไฟล์ .xlsx
  • ไอคอน “i” ข้างหัวการ์ด — ชี้หรือแตะเพื่อดูว่าตัวเลขนั้นคำนวณอย่างไร
  • ปุ่ม AI (มีไอคอน ✨/🤖) — ให้ AI ช่วยสรุปหรือร่างข้อความ ผลลัพธ์ควรตรวจทานก่อนนำไปใช้เสมอ
เมื่อมีเวอร์ชันใหม่ ระบบจะโหลดใหม่เองถ้าไม่ได้กรอกฟอร์มค้างอยู่ ถ้ากรอกค้างอยู่จะขึ้นแถบ 🚀 มีอัปเดตเวอร์ชันใหม่ของระบบ ให้บันทึกงานก่อนแล้วจึงกด โหลดใหม่ตอนนี้

หลังอัปเดต เข้าระบบครั้งแรกจะขึ้นหน้าต่าง มีอะไรใหม่ บอกว่าเปลี่ยนอะไรและอยู่ตรงไหน (คลิกเลขเวอร์ชันใต้ชื่อระบบเพื่อเปิดดูอีกครั้งได้) เปิดหน้าต่างแล้วเสียง AI ภาษาไทยจะกล่าวทักทายชื่อคุณ แล้วอ่านหัวข้อของทุกรายการให้ฟังเองทีละข้อ ไม่ต้องกด พร้อมไฮไลต์ข้อที่กำลังอ่าน (รายละเอียดอ่านเองในหน้าต่าง) (รอเตรียมเสียงครู่หนึ่งก่อนเริ่ม) ถ้าปุ่มมุมขวาบนขึ้นว่า 👆 แตะที่ใดก็ได้เพื่อฟัง แปลว่าเบราว์เซอร์ยังไม่อนุญาตให้เล่นเสียงเอง แตะหน้าจอครั้งเดียวก็เริ่มอ่าน · กด ⏹ หยุดอ่าน หรือปิดหน้าต่างเพื่อหยุด กด 🔊 AI อ่านให้ฟัง เพื่อฟังซ้ำ อย่าลืมเปิดเสียงลำโพงของเครื่อง

เข้าระบบครั้งแรกจะมี แนะนำการใช้งาน พาดูทีละเมนู (เปิดดูอีกครั้งได้ที่ กดชื่อผู้ใช้มุมซ้ายล่าง › 🧭 แนะนำการใช้งาน) เสียง AI จะกล่าวทักทาย แล้วพูดอธิบายเมนูของแต่ละขั้นให้ฟังทุกครั้งที่กด ถัดไป · ไม่อยากฟังเสียง กดปุ่ม 🔊 มุมขวาบนของการ์ดให้เป็น 🔇 (ระบบจำไว้ครั้งต่อไป)

การแจ้งเตือน

กระดิ่งแจ้งเตือนในระบบ

กดกระดิ่งที่มุมขวาบนเพื่อดูรายการ กดแต่ละรายการเพื่อไปยังหน้านั้น จะเห็นเฉพาะเรื่องในเมนูที่คุณมีสิทธิ์

  • Advance เกินกำหนด — ใบเบิกที่เลยกำหนดเคลียร์แล้วแต่ยังไม่เคลียร์
  • การลาของคุณรออนุมัติ — ใบลาของคุณที่ยังไม่ได้รับการอนุมัติ
  • Ticket ใหม่ที่ยังไม่ได้ตอบ — เรื่องแจ้งปัญหาใหม่ที่ทีมยังไม่ได้ตอบลูกค้า
  • คำขอรีเซ็ตรหัสผ่าน — เฉพาะ Admin

แจ้งเตือนแม้ปิดหน้าเว็บ (Web Push)

สำหรับผู้ที่ดูแล Helpdesk: เปิดกระดิ่งแล้วกด 📳 เปิดแจ้งเตือนเมื่อปิด WebApp และกดอนุญาตเมื่อเบราว์เซอร์ถาม เมื่อลูกค้าแจ้งเรื่องใหม่ผ่านฟอร์มเว็บหรือตอบข้อความใน Ticket เครื่องของคุณจะเด้งแจ้งเตือนแม้ปิดหน้าเว็บอยู่

บน iPhone ต้อง เพิ่มแอปลงหน้าจอโฮม ก่อน จึงจะเปิดการแจ้งเตือนได้ ถ้าปุ่มขึ้น 🚫 เบราว์เซอร์บล็อกการแจ้งเตือน ให้ไปอนุญาตการแจ้งเตือนในการตั้งค่าเบราว์เซอร์ก่อน

แจ้งเตือนเข้ากลุ่มแชททีม

ระบบส่งข้อความเข้ากลุ่มแชทของทีมให้อัตโนมัติ (ผู้ดูแลระบบตั้งค่าใน Admin Panel › การแจ้งเตือน) ได้แก่ การลางานใหม่/อนุมัติ/ไม่อนุมัติ (มีลิงก์อนุมัติด่วน), ความเคลื่อนไหวของ Advance, วันเริ่ม/สิ้นสุด/ปิดโครงการ, Ticket ด่วนที่สุดและการโทรด่วนจากลูกค้า, การลงทะเบียนอบรม และคำขอใช้งานทีม Server

ตั้งค่า Token แจ้งเตือนกลุ่ม

  1. Admin Panel › 🔔 การแจ้งเตือน — ด้านบนบอกว่ากี่ช่องทางพร้อมใช้งาน ทางซ้ายเป็นรายการทุกช่องทาง จุดเขียว = พร้อมใช้ · จุดส้ม = ยังไม่ตั้ง Token กดเลือกช่องทางเพื่อดูรายละเอียดทางขวา
  2. ช่องทางที่ ยังไม่ตั้ง: วาง Token ในช่องแล้วกด 💾 บันทึก (หรือกด Enter)
  3. ช่องทางที่ เชื่อมต่อแล้ว (แสดง 4 ตัวท้ายของ Token): กด 🧪 ทดสอบส่ง เพื่อส่งข้อความทดสอบเข้ากลุ่ม · จะเปลี่ยนให้กด เปลี่ยน Token แล้ววางค่าใหม่
  4. หยุดแจ้งเตือนเรื่องนั้น: กด 🗑 ลบ Token ท้ายหน้า แล้วกด ลบเลย เพื่อยืนยัน · หัวข้อ จะแจ้งเตือนเมื่อ บอกว่าช่องทางนั้นส่งข้อความตอนไหนบ้าง
Token เก็บที่เซิร์ฟเวอร์เท่านั้น บันทึกแล้วหน้าเว็บจะไม่แสดงค่าเต็มอีก (เห็นแค่ 4 ตัวท้าย) และข้อความแจ้งเตือนทุกเรื่องถูกส่งจากเซิร์ฟเวอร์ ไม่ผ่านเครื่องผู้ใช้ · ตั้ง/ลบ Token ได้เฉพาะผู้ที่ Login และมีสิทธิ์ดู Admin Panel ระบบบันทึกทุกครั้งว่าใครแก้

ถาม AI

น้องบอท 🤖 ที่ลอยอยู่มุมขวาล่างของทุกหน้า (มือถือ: อยู่เหนือแถบเมนูล่าง) หรือกด Ctrl+K (Mac: ⌘K)

พิมพ์คำถามเป็นภาษาพูดได้เลย AI จะแปลงคำถามเป็นเงื่อนไขค้นหา ดึง ข้อมูลจริง จากระบบ แล้วเขียน 💬 คำตอบ สรุปให้อ่านบนสุด (ตอบตรงคำถามก่อน เช่น มี/ไม่มี กี่รายการ แล้วตามด้วยประเด็นสำคัญ) ด้านล่างเป็นรายการจริงที่ใช้ตอบ ตัวเลขทั้งหมดนับจากฐานข้อมูล ไม่ได้มาจาก AI แต่ง

  1. กดน้องบอท หน้าต่างแชทจะเปิดขึ้น (กดบอทอีกครั้ง, ✕ หรือ Esc เพื่อปิด — บทสนทนายังอยู่ เปิดใหม่ถามต่อได้)
  2. ถ้าบอทบังหน้าจอ ชี้เมาส์ที่บอทแล้วกด ✕ มุมบนขวาของบอท (มือถือ: ✕ แสดงตลอด) บอทจะหลบเหลือแถบ 🤖 เล็ก ๆ ที่ขอบขวา กดแถบนั้นเพื่อเรียกบอทกลับ — ระหว่างซ่อนยังกด Ctrl+K เปิดแชทได้ และระบบจำการซ่อนไว้ในเบราว์เซอร์นี้
  3. พิมพ์คำถาม เช่น “รพ.ไหนมีปัญหาค้างเกิน 7 วันมากที่สุด”, “สัปดาห์หน้าใครว่างบ้าง”, “Advance ที่เลยกำหนดเคลียร์” หรือกดตัวอย่างใต้ 💡 ลองถามแบบนี้ ในข้อความทักทาย
  4. กด Enter เพื่อส่ง (Shift+Enter = ขึ้นบรรทัดใหม่) บอทจะตอบกลับเป็นข้อความในแชท ถามต่อได้เรื่อย ๆ
  5. อ่าน 💬 คำตอบ แล้วตรวจบรรทัด 🤖 AI เข้าใจว่า: … และป้ายเงื่อนไขว่าตรงกับที่ต้องการ
  6. กดรายการในคำตอบเพื่อเปิดดูรายละเอียดในหน้านั้น (จอคอมแชทยังลอยค้างไว้ให้ถามต่อ · มือถือแชทจะปิดให้อัตโนมัติ)
  7. กด บนหัวแชทเพื่อล้างบทสนทนาและเริ่มใหม่

แชทแสดงเฉพาะ 💬 คำตอบ ส่วนข้อมูลที่ค้นได้ทั้งหมด (AI เข้าใจว่า, เงื่อนไข, รายการที่คลิกเปิดได้) พับไว้ที่ 📋 ดูข้อมูลทั้งหมด กดเพื่อกางดู — ถ้า AI สรุปคำตอบไม่ได้ จะกางรายการให้เอง

สรุปคำตอบเสร็จแล้ว เสียง AI จะอ่าน 💬 คำตอบ ให้ฟังเองทันที ไม่ต้องกด (ไม่อยากให้อ่านเอง กดปุ่ม 🔊 บนหัวแชทให้เป็น 🔇 ระบบจำไว้ครั้งต่อไป) · กด 🔊 ฟังคำตอบ (ท้ายบรรทัด AI เข้าใจว่า ในแต่ละคำตอบ) เพื่อฟังซ้ำหรือฟังคำตอบเก่า (ถ้ายังไม่มีคำตอบสรุป จะอ่าน: สิ่งที่ AI เข้าใจ → จำนวนที่พบ → 5 รายการแรก (ถ้าแยกกลุ่ม = 3 กลุ่มที่มากที่สุด) พร้อมไฮไลต์รายการที่กำลังอ่าน) กด ⏹ หยุดอ่าน, ถามใหม่ หรือปิดแชทเพื่อหยุด

ค้นได้จากทุกข้อมูลที่คุณมีสิทธิ์ดู เช่น Ticket, ปัญหาโครงการ, โครงการ, การลา, คนว่าง, Advance, ค่าใช้จ่าย, ที่พัก, สัญญา, โรงพยาบาล, คำขอทีม Server และคลังคำตอบผู้ช่วยทีม ถ้าบริการ AI ขัดข้อง ระบบจะค้นด้วยคำสำคัญแทน

  • ถามคำว่า “ปัญหา” เฉย ๆ ระบบค้นทั้ง Ticket และปัญหาการใช้งานในโครงการพร้อมกัน เช่น “ปัญหา รพ.ทุ่งช้างมีที่ยังไม่ได้แก้ไขไหม”
  • คำว่า ยังไม่ได้แก้ / ยังค้าง = เฉพาะเรื่องที่ยังเปิดอยู่ · แก้แล้ว / ปิดแล้ว = เฉพาะที่เสร็จแล้ว
  • พิมพ์ชื่อ รพ. ตกวรรณยุกต์หรือสะกดใกล้เคียง (เช่น “ทุงช้าง”) ระบบหาชื่อที่ใกล้ที่สุดให้ และบอกไว้บนป้ายเงื่อนไข
  • ถามกว้าง ๆ เช่น “รพ.ทุ่งช้างมีอะไรบ้าง” จะแสดงเฉพาะข้อมูลที่ผูกกับ รพ. นั้นจริง (ไม่ดึงวันหยุดหรือข้อมูลที่ไม่เกี่ยวมาปน)
  • ถามวิธีใช้งาน เช่น “ขอใช้ทีม Server ทำยังไง” AI ตอบว่าอยู่เมนูไหนจากเมนูที่คุณมีสิทธิ์

ใช้งานบนมือถือ & ติดตั้งแอป

  • บนจอมือถือจะมี แถบเมนูล่าง: Overview, โครงการ, Advance, รพ. และ เพิ่มเติม (เปิดเมนูทั้งหมด)
  • ตารางจะแสดงเป็นการ์ด ข้อความยาวที่ถูกตัดด้วย “…” แตะเพื่อดูทั้งหมด
  • ปุ่มบนแถบเครื่องมือจะเหลือแต่ไอคอน กดค้างเพื่อดูชื่อปุ่ม

  • ประโยคสรุปตัวใหญ่ — บอกยอดปิดโครงการสะสม ณ เดือนที่เลือก เทียบเป้าหมาย และส่วนที่ขาด
  • กราฟเส้น — เส้นเขียวทึบ = ยอดปิดที่เกิดขึ้นจริง · เส้นเขียวประ = พยากรณ์ · แถบเขียวจาง = ช่วงที่เป็นไปได้ · เส้นม่วงประ = เป้าหมายสะสม · เส้นแดงแนวตั้ง = ส่วนที่ขาดเป้า · เส้นจุดสีเทา = สถานการณ์อื่น
  • แถบเลื่อนเวลา — เลื่อน/กดชื่อเดือน/กดที่กราฟ เพื่อดูเดือนนั้น ปุ่ม เล่นไทม์ไลน์ เดินทีละเดือนอัตโนมัติ ปีปัจจุบันมองล่วงหน้าถึง มิ.ย. ปีถัดไป
  • สถานการณ์ — ระวัง ปิดช้ากว่าวันสิ้นสุด 1–3 เดือน และยอดขายใหม่ลดลง 25% · คาดการณ์ ปิดหลังวันสิ้นสุด 1–2 เดือน · เร่งปิดงาน ปิดตรงเดือนที่สิ้นสุด (งานที่เลยกำหนดปิดเดือนนี้) และยอดขายใหม่เพิ่ม 15%
  • ตัวเลข 4 ช่องด้านขวา — ปิดโครงการสะสม, ออกโครงการสะสม, งานค้างรอปิด, ภาระทีม (จำนวนโครงการ/คนเกินกำลัง) ของเดือนที่เลือก พร้อมข้อความแนะนำ 3 ข้อ
หัวข้อวิธีคิด
ยอดปิดจริงมูลค่าโครงการที่อยู่ขั้นตอน "ปิดโครงการ" นับตามเดือนของวันสิ้นสุด (ปิดก่อนวันสิ้นสุด = นับเดือนนี้)
ยอดพยากรณ์โครงการที่ยังไม่ปิด จะปิดตามเดือนของวันสิ้นสุด + ระยะเวลาตามสถานการณ์ · ยอดขายใหม่ใช้ค่าเฉลี่ยรายเดือนของปีนี้ และคาดว่าจะปิดหลังเริ่ม 3 เดือน
ช่วงที่เป็นไปได้±7% ต่อเดือนที่มองไปข้างหน้า
เป้าหมายสะสมเป้าทั้งปี ÷ 12 × จำนวนเดือน · ถ้ายังไม่ตั้งเป้าปีถัดไป ใช้เท่ากับปีนี้ไปก่อน

2. สถานะวันนี้ (KPI 8 ช่อง)

เป้าหมายปี, ออกโครงการแล้ว, ปิดโครงการ (รับรู้รายได้), ออกแล้วยังไม่ปิด, จำนวนโครงการ, การใช้ทีมงาน, Adv. ค้างเคลียร์, Helpdesk เปิดอยู่ แถบใต้ตัวเลขมีขีดบอก สัดส่วนเวลาที่ผ่านไปของปี ไว้เทียบว่าเร็ว/ช้ากว่าเวลา ช่องที่มีเรื่องค้างกดเพื่อดูรายการได้

3. การเงิน & เป้าหมาย

  • เป้าหมายเทียบผลงาน — กราฟแท่ง เป้าหมาย / ออกโครงการ / ปิดโครงการ แยกกลุ่ม ตามตารางเป้าหมายประจำปีด้านล่าง (สลับ รวมกลุ่ม / แยกประเภท ได้ ตั้งเป้าที่เมนู เป้าหมายทีม)
  • สัดส่วนมูลค่าตามประเภท — วงแหวนมูลค่าโครงการแยกประเภท
  • ยอดปิดโครงการรายเดือน — แท่งทึบ = ปิดแล้ว · แท่งจาง = คาดว่าจะปิด · เส้นยอดสะสมเทียบเป้าสะสม
  • Financial Alerts (Adv.) — จำนวน Adv. ที่ยังไม่เคลียร์แยกสถานะ (แยก "เลยกำหนด" ออกมา) และรายการใกล้ครบกำหนดเคลียร์

4. พอร์ตโครงการ

  • โครงการตาม Stage และ สุขภาพโครงการที่ยังเปิด (ปกติ / เสี่ยง / ล่าช้า)
สุขภาพเงื่อนไข
เสร็จคืบหน้า 100% หรือปิดโครงการแล้ว (ไม่แสดงในวงแหวน)
ล่าช้าเลยวันสิ้นสุดแล้ว
เสี่ยงคืบหน้าช้ากว่าแผนตั้งแต่ 25% — แผนคิดจากสัดส่วนวันที่ผ่านไป เช่น โครงการ 5 วัน วันที่ 2 ควรได้ 40% · หรือถึงวันสุดท้ายแล้วคืบหน้ายังไม่ถึง 80% (ยังไม่ถึงวันเริ่ม = ปกติ) — ป้ายในรายการจะบอกเหตุผล เช่น “ช้ากว่าแผน 30%”
ปกติกรณีอื่น ๆ

5. ทรัพยากรบุคคล

  • ภาระงานรายเดือน — จำนวนโครงการที่ดำเนินอยู่แต่ละเดือน แยกประเภท
  • สถานะทีมงาน — เกินกำลัง (>3 โครงการ) / ปกติ (1–3) / ว่าง นับจากโครงการที่คาบเกี่ยวเดือนปัจจุบัน
  • ภาระงานรายบุคคล — มุมมอง รูปคน: 1 คน = 1 รูป สีเติมจากเท้าขึ้นไปตามจำนวนโครงการ (เต็มตัว = 5) เขียว ว่าง · ฟ้า ปกติ · ส้ม เต็มมือ · แดง เกินกำลัง เลือกเดือนได้ เรียงคนงานมากไว้ก่อน · มุมมอง ทั้งปี (คน × เดือน): กราฟ 3D หมุนได้ ดูแนวโน้มทั้งปี กดที่คนเพื่อดูภาระงาน 12 เดือนและรายชื่อโครงการ · ช่อง ทุกแผนก ด้านบนเลือกดูเฉพาะแผนกได้ (ใช้ทั้งสองมุมมอง และจำค่าที่เลือกไว้)

6. บริการ & ความเสี่ยง

  • Helpdesk ที่ยังเปิด — แยกตามความเร่งด่วน เทียบจำนวนที่เกิน SLA (แสดงเมื่อมีสิทธิ์ดู Helpdesk)
  • ศูนย์รวมสิ่งที่ต้องจัดการ — Adv. เลยกำหนด, โครงการเลยวันสิ้นสุด, Helpdesk เกิน SLA, ที่พักยังไม่อนุมัติ, Adv. รออนุมัติ, งานติดตั้งเกินกำหนด, ใบลารออนุมัติ เรียงตามความรุนแรง กดเพื่อดูรายการหรือไปยังเมนูนั้น

7. โครงการที่ต้องจับตา

รายการโครงการตามตัวกรองด้านบนของหน้า จัดกลุ่มตามประเภทโครงการ (สีของประเภท) แต่ละแถวมีป้ายสุขภาพ, ป้าย เหลือ / เลย N วัน, ทีมงาน, ความคืบหน้า และมูลค่า กดแถวเพื่อเปิดโครงการ แสดงสูงสุด 10 โครงการต่อแท็บ ปุ่ม ดูทั้งหมดในเมนูโครงการ › ไปยังตารางเต็ม (ค้นหา/เรียง/Export Excel อยู่ที่เมนู โครงการ)

แท็บแสดง
ต้องจับตาโครงการล่าช้า (เลยวันสิ้นสุด) และเสี่ยง (ช้ากว่าแผนตั้งแต่ 25% หรือถึงวันสุดท้ายแล้วคืบหน้า < 80%) เรียงจากเลยกำหนดนานสุด
รอปิดโครงการคืบหน้า 100% / เสร็จสิ้น / เลยวันสิ้นสุด แต่ยังไม่อยู่ขั้นตอนปิดโครงการ เรียงมูลค่ามากก่อน (มูลค่าที่ยังไม่รับรู้รายได้)
ใกล้ครบกำหนด 30 วันยังไม่เสร็จ และวันสิ้นสุดเหลือไม่เกิน 30 วัน (รวมที่เลยกำหนด)
ทั้งหมดทุกโครงการตามตัวกรอง เรียง ล่าช้า → เสี่ยง → ปกติ → เสร็จ

โครงการ

เมนู Workspace › โครงการ

ทะเบียนโครงการทั้งหมด แยกแท็บตามกลุ่มโครงการ (ทั้งหมด, ติดตั้งระบบ Onsite, Revisit ฯลฯ) ค้นหา กรองตามปี/ประเภทโครงการ/Stage และส่งออก Excel ได้

รายการจัดกลุ่มตามประเภทโครงการ (เช่น คลังสินค้า, บัญชี) หัวกลุ่มบอกจำนวนโครงการ ใช้ช่อง ทุกประเภทโครงการ เลือกดูเฉพาะบางประเภทได้ (เลือกได้หลายค่า) โครงการที่ยังไม่ระบุประเภทอยู่กลุ่มสุดท้าย

ใต้วันสิ้นสุดมีแถบเวลาที่ผ่านไปของโครงการ พร้อมป้าย เหลือ N วัน (สีส้มเมื่อเหลือ ≤ 15 วัน) / เลยกำหนด N วัน (สีแดง) / เริ่มใน N วัน — ไม่แสดงเมื่อความคืบหน้าครบ 100%

ตารางแสดงทีมงาน วันเริ่ม/สิ้นสุด สถานะที่พัก (✅ รายวัน / ✅ รายเดือน / ⏳ รออนุมัติ) สถานะ Advance และวันนัด Revisit

เพิ่ม / แก้ไขโครงการ

  1. กด เพิ่มโครงการ (Admin/PM) หรือกดที่แถวโครงการเพื่อแก้ไข
  2. แท็บ 📋 ข้อมูลโครงการ — กรอกช่องที่มี * ให้ครบ: ชื่อโครงการ, กลุ่ม, ประเภท, เจ้าของไซต์, ชื่อผู้ติดตั้ง, วันเริ่ม, วันสิ้นสุด และงบประมาณ เลือกโรงพยาบาลโดยพิมพ์ค้นหา หรือกด 🤖 AI หา รพ.
  3. แท็บ 👥 ทีมงาน (แสดงเมื่อใส่วันเริ่ม-สิ้นสุดแล้ว) — กด ＋ หน้าชื่อเพื่อเพิ่มคน ปรับวันทำงานของแต่ละคนได้ ถ้าชนกับงานอื่น/วันลา ระบบจะเตือน ⚠️ พบงานซ้อนทับ!
  4. แท็บ 📍 รอบเข้าไซต์หลายช่วง — ถ้าเข้าไซต์หลายรอบ กด + เพิ่มรอบเข้าไซต์ ระบุวัน วัตถุประสงค์ สถานะรอบ และทีมของรอบนั้น
  5. กด 💾 บันทึก
ข้อมูลทีมงานและวันที่ของโครงการถูกนำไปใช้ต่อใน Timesheet, ภาระงานทีม, ปฏิทินทีม, ทีมว่าง และ Advance อัตโนมัติ จึงควรกรอกให้ถูกต้อง

ลบโครงการ

ปุ่ม 🗑 แสดงเฉพาะผู้มีสิทธิ์ลบ และลบได้เฉพาะโครงการที่ยังไม่มี Advance และที่พัก

Advance (เบิกเงินทดรองจ่าย)

เมนู Workspace › Advance › แท็บ 💳 รายการเบิก

บันทึกและติดตามใบเบิกเงินล่วงหน้าของแต่ละโครงการ ตั้งแต่ร่างจนเคลียร์เงิน ตัวเลขแดงข้างเมนูคือจำนวนใบที่เลยกำหนดเคลียร์

สถานะของใบเบิก

สถานะความหมาย
📝 Draftร่าง ยังไม่ส่งขออนุมัติ (ลบได้เฉพาะสถานะนี้)
⏳ รออนุมัติส่งขออนุมัติแล้ว
👍 อนุมัติแล้วอนุมัติแล้ว รอจ่ายเงิน
💸 เบิกแล้วได้รับเงินแล้ว (ระบบเปลี่ยนให้อัตโนมัติเมื่อถึงวันเริ่มโครงการ)
🧾 รอเคลียร์จบงานแล้ว รอส่งค่าใช้จ่ายจริง (ระบบเปลี่ยนให้อัตโนมัติหลังวันสิ้นสุด 3 วัน)
✅ เคลียร์แล้วเคลียร์เงินเรียบร้อย ค่าใช้จ่ายถูกส่งเข้าหน้างบประมาณ

สร้างใบเบิก

  1. กด New Advance
  2. เลือกโครงการ (ติ๊ก แสดงโครงการที่สิ้นสุดแล้ว ถ้าหาไม่เจอ) ระบบตั้ง กำหนดเคลียร์ = วันสิ้นสุด + 7 วัน (เลื่อนเป็นวันทำงาน) ให้อัตโนมัติ
  3. กรอกเลขที่ Advance, วัตถุประสงค์ (ติดตั้งระบบ / Revisit / MA), จำนวนเบิก, วันที่ขอ และหมายเหตุ
  4. กด 💾 บันทึก — ใบใหม่จะเป็นสถานะ Draft

เลื่อนสถานะ

เปิดใบเบิก (✏️) แล้วกด ขั้นถัดไป › หรือ ‹ ย้อนกลับ ระบบบันทึกทันทีและแจ้งเตือนกลุ่มทีม

เคลียร์เงิน

เมื่ออยู่สถานะ รอเคลียร์ หรือ เคลียร์แล้ว จะมีส่วนกรอกเพิ่ม:

  • 🧾 รายการค่าใช้จ่าย — เลือกหมวด (ค่าเดินทาง, ค่าน้ำมัน, ค่าที่พัก, ค่าอาหาร ฯลฯ) ใส่รายละเอียดและจำนวนเงิน กด + เพิ่มรายการ
  • 👷 ค่าแรง + เบี้ยเลี้ยง — ดึงรายชื่อทีมและวันทำงานจากโครงการให้อัตโนมัติ กรอกวันหยุดที่ทำงานเอง ติ๊ก 📍 พื้นที่ชายแดน เพื่อใช้อัตราชายแดน
  • 💰 สรุปค่าใช้จ่าย — ระบบรวมยอดให้ ช่อง “จ่ายจริง” คือค่าใช้จ่ายทั่วไป (ไม่รวมค่าแรง)

บนการ์ด “ส่วนต่าง” ค่าบวก = ต้องคืนเงิน ค่าลบ = ใช้เกิน ใบที่เลยกำหนดจะมีขอบแดงและ ⚠️

บันทึกเป็น เคลียร์แล้ว เมื่อไร รายการค่าใช้จ่ายจะถูกคัดลอกไปที่ งบประมาณ › รายการค่าใช้จ่าย อัตโนมัติ (ไม่ต้องกรอกซ้ำ)

เอกสารประกอบ / แบบฟอร์ม

เมนู Advance › แท็บ 🧾 เอกสารประกอบ

กรอกแบบฟอร์มทางซ้าย และดูตัวอย่างเอกสารจริงทางขวาแบบทันที เลือกชนิดเอกสารจากดรอปดาวน์ด้านบน:

FM-AC-01เอกสารประกอบ Adv. (ใบเคลียร์ค่าใช้จ่าย) — ค่าเดินทาง ค่าที่พัก ค่าอื่น ๆ และรายชื่อผู้ปฏิบัติงาน (สูงสุด 12 คน) ยอดขอเบิกคำนวณให้อัตโนมัติ
FM-AC-02แบบฟอร์มการออกปฏิบัติงาน — แผนก, สถานที่ (เลือก รพ. แล้วเติมจังหวัด/ผู้ติดต่อให้), งานที่ไป, การเตรียมความพร้อม, ข้อมูลบัญชี
หนังสือแจ้งออกไซต์หนังสือแจ้งโรงพยาบาลก่อนเข้าปฏิบัติงาน — ระบบ, เรื่องที่ดำเนินการ, วันที่, รายชื่อผู้เข้าปฏิบัติงาน, ช่องทางจัดส่ง

ขั้นตอน

  1. เลือกชนิดเอกสาร แล้วกด + ฟอร์มใหม่ (หรือเลือกฟอร์มที่บันทึกไว้จากดรอปดาวน์)
  2. เลือก อ้างอิงโครงการ (ถ้ามี) ระบบจะเติมวันที่ สถานที่ ทีมงาน และข้อมูลที่เกี่ยวข้องให้
  3. ตรวจและแก้ไขข้อมูลให้ครบ — ช่องบังคับ: FM-AC-01 ต้องมีชื่อผู้ปฏิบัติงาน, FM-AC-02 และหนังสือแจ้งต้องมีสถานที่
  4. กด 💾 บันทึก แล้วกด 🖨️ พิมพ์ หรือ 📝 Word เพื่อดาวน์โหลดไฟล์ .doc

ลบฟอร์มที่บันทึกไว้ด้วย 🗑 ลบ (ต้องมีสิทธิ์ลบ ลบแล้วกู้คืนไม่ได้) ถ้าไม่มีสิทธิ์แก้ไข ช่องกรอกทั้งหมดจะถูกล็อกไว้

จัดหาที่พัก

เมนู Workspace › จัดหาที่พัก

รวบรวมตัวเลือกที่พักของแต่ละโครงการ เปรียบเทียบราคา และอนุมัติ แสดงเฉพาะโครงการที่มีข้อมูลที่พักแล้ว แบ่งกลุ่มตามประเภทโครงการ

เพิ่มที่พัก

  1. กด เพิ่มที่พัก แล้วเลือกโครงการ
  2. กด + เพิ่มตัวเลือกใหม่ กรอกชื่อที่พัก เบอร์ติดต่อ ลิงก์แผนที่ และวัน Check-in/Check-out (ค่าเริ่มต้น = ก่อนวันเริ่ม 1 วัน ถึงวันสิ้นสุด)
  3. กรอกราคาได้ทั้ง 📅 รายวัน และ 📆 รายเดือน: จำนวนห้องเตียงเดี่ยว/เตียงคู่ × ราคา, สิ่งอำนวยความสะดวก, ค่ามัดจำ, ค่าน้ำ-ไฟ ระบบรวมยอดตลอดช่วงให้
  4. กด 💾 บันทึกที่พัก — เพิ่มได้หลายตัวเลือกเพื่อเปรียบเทียบ (+ ตัวเลือก)

อนุมัติ (ผู้มีสิทธิ์อนุมัติที่พัก)

  • กด ✅ อนุมัติ ที่แถวราคารายวันหรือรายเดือนของตัวเลือกที่ต้องการ ยกเลิกด้วย ↩ ยกเลิก
  • แต่ละโครงการอนุมัติได้ 1 ตัวเลือกต่อแบบ (รายวัน/รายเดือน แยกกัน) อนุมัติตัวใหม่ ตัวเดิมจะถูกยกเลิกให้อัตโนมัติ
  • กด 🤖 AI ให้ AI เปรียบเทียบ (เตียงพอทีมไหม, ราคาต่อคนต่อคืน, ค่าน้ำไฟ, สิ่งอำนวยความสะดวก) แล้วกด ✅ อนุมัติตามคำแนะนำ ได้

สถานะที่พักแสดงต่อใน Delivery Board (🏨 ที่พักรออนุมัติ) หน้าโครงการ และ AI สรุปประจำวัน

ติดตามสถานะโครงการ (Implementation Tracker)

เมนู Workspace › ติดตามสถานะโครงการ

ติดตามงานติดตั้งระบบที่โรงพยาบาลแบบละเอียด โครงสร้าง โครงการ → Phase → งาน (Task) → เช็คลิสต์ พร้อมบันทึกปัญหาการใช้งาน แบบฟอร์ม การอบรม และรายงาน

แท็บหลัก

  • 📊 ทุกโครงการ — แดชบอร์ดคะแนนสุขภาพทุกโครงการ, แผง 📌 ต้องจัดการ (เกินกำหนด / 7 วันข้างหน้า / ปัญหาค้าง ≥7 วัน), ภาระงานรายคน และ 🤖 AI สรุปภาพรวม
  • 🗂️ รายโครงการ — เข้าไปจัดการโครงการเดียว (เลือกโครงการจากช่องค้นหาด้านบน)
  • 📐 Template — แม่แบบ Phase/Task/เช็คลิสต์ สำหรับสร้างโครงการใหม่

คะแนนสุขภาพโครงการ (0–100)

หักคะแนนจาก ความล่าช้าเทียบแผน, งานเกินกำหนด, ปัญหาที่ยังเปิด และไม่มีความเคลื่อนไหวเกิน 7 วัน — 🟢 ปกติ ≥80 · 🟡 ต้องติดตามพิเศษ 60–79 · 🔴 ล่าช้า <60

เพิ่มโครงการเข้าระบบติดตาม

  1. กด + เพิ่มโครงการ แล้วเลือกโครงการจากเมนูโครงการ
  2. เลือก ใช้ Template Checklist (ถ้ามี) — รายการแสดงเฉพาะ Template ของประเภทโครงการที่เลือก + ใช้ร่วมทุกประเภท (มี Template ของประเภทนั้น ระบบเลือกให้อัตโนมัติ) ระบบจะสร้าง Phase/งาน/เช็คลิสต์ และกระจายวันครบกำหนดให้
  3. กด 💾 บันทึก — ชื่อ วันที่ เจ้าของไซต์ ผู้ติดตั้ง ดึงจากเมนูโครงการ (แก้ที่เมนูโครงการเท่านั้น)

แท็บในแต่ละโครงการ

🗃️ งาน

  • มุมมอง Phase (ลากเรียงลำดับได้), List และ Kanban (ลากการ์ดเพื่อเปลี่ยนสถานะ)
  • เมนูซ้าย: ➕ เพิ่ม Phase, 📐 บันทึกเป็น Template, ✏️ แก้ไขโครงการ, 🗑️ ลบโครงการ
  • เปิดงานเพื่อกำหนดผู้รับผิดชอบ (จากทีมโครงการ), ความสำคัญ, วันเริ่ม/กำหนดเสร็จ, สถานะ, เช็คลิสต์ และความคิดเห็น
  • หน้ารายละเอียดงานแบ่ง 2 ฝั่ง — ซ้าย: ชื่องาน รายละเอียด เช็คลิสต์ ความคิดเห็น · ขวา: สถานะ ผู้รับผิดชอบ ความสำคัญ ช่วงเวลา
  • สถานะ / ความสำคัญ กดปุ่มเดียวเลือกได้เลย · ผู้รับผิดชอบ กด มอบให้ฉัน หรือชื่อเล่นคนในทีม (หรือค้นหาจากช่องเลือก) · กำหนดเสร็จ กดปุ่มลัด +1 วัน +3 วัน +1 สัปดาห์ สิ้นเดือน (นับจากวันเริ่ม) ระบบบอกจำนวนวันรวม/วันที่เหลือให้
  • บันทึกอัตโนมัติ — งานที่มีอยู่แล้ว แก้ช่องไหนระบบบันทึกให้ทันที (ดูเวลาบันทึกล่าสุดมุมขวาบน) · Ctrl+Enter บันทึกและปิด
  • เช็คลิสต์ — ติ๊กรายการแรก งานเปลี่ยนเป็น “กำลังดำเนินการ” ให้เอง · ติ๊กครบทุกรายการระบบถามว่าจะปิดงานเลยไหม · ☑ ติ๊กทั้งหมด / ล้างทั้งหมด · คลิกตรงไหนของแถวก็ติ๊กได้ทันที (บันทึกให้เบื้องหลัง) · เช็คลิสต์ตั้งแต่ 6 ข้อขึ้นไปมีตัวกรอง ทั้งหมด / ยังไม่ทำ / เสร็จแล้ว — เปิดงานที่ยังติ๊กไม่ครบ ระบบเลือก “ยังไม่ทำ” ให้เลย (ครบแล้วแสดงทั้งหมด) ติ๊กไล่ลงไปได้ รายการที่ติ๊กแล้วจะหายจากรายการ · กด Shift ค้างแล้วคลิก = ติ๊กทั้งช่วงจากรายการที่คลิกล่าสุด · พิมพ์แล้วกด Enter เพิ่มรายการ หรือวางข้อความหลายบรรทัด (เช่นคัดลอกจาก Excel/LINE) ระบบแยกเป็นหลายรายการให้
  • ✅ ทำเสร็จแล้ว ติ๊กเช็คลิสต์ทั้งหมดและปิดงานในครั้งเดียว
  • ‹ › มุมขวาบน ไปงานก่อนหน้า/ถัดไปของโครงการโดยไม่ต้องปิดหน้าต่าง · ⧉ คัดลอกเป็นงานใหม่ สร้างงานซ้ำพร้อมเช็คลิสต์ · ตอนเพิ่มงาน กด 💾 บันทึก + เพิ่มงานถัดไป เพื่อเพิ่มต่อเนื่อง (ใช้ผู้รับผิดชอบ/ความสำคัญ/วันที่เดิม)
  • เพิ่มเช็คลิสต์ตอนสร้างงานได้เลย — ในหน้าต่าง เพิ่ม Task ใหม่ พิมพ์รายการเช็คลิสต์แล้วกด Enter (วางหลายบรรทัด = หลายรายการ) ไม่ต้องบันทึกงานก่อน ระบบสร้างเช็คลิสต์ให้พร้อมกันตอนกดบันทึก · ความคิดเห็นเพิ่มได้หลังบันทึก
  • 📋 วางเป็นข้อความ (หลายงาน) — ในหน้าต่าง เพิ่ม Task ใหม่ สลับโหมดด้านบน แล้ววางรายการจาก Excel / Word / LINE: 1 บรรทัด = 1 งาน · ถ้าต้องการแบ่ง Phase: บรรทัดปกติ = Phase (ชื่อตรงกับ Phase ที่มี = ใช้ Phase เดิม ไม่ตรง = สร้าง Phase ใหม่) · ขึ้นต้นด้วย - = งาน · ย่อหน้า (Tab) แล้ว - = เช็คลิสต์ · (3) ท้ายงาน = จำนวนวัน (กำหนดเสร็จนับจากวันเริ่ม) · งานที่ไม่อยู่ใต้หัว Phase เข้า Phase ตั้งต้น · สถานะ/ผู้รับผิดชอบ/ความสำคัญ/วันที่ด้านขวาใช้กับทุกงาน · ดูตัวอย่างก่อนกด 💾 บันทึก n งาน
  • ความคืบหน้าคำนวณเอง: งาน = เช็คลิสต์ที่ติ๊ก, Phase = เฉลี่ยงาน, โครงการ = เฉลี่ย Phase

🩹 ปัญหา (บันทึกปัญหาการใช้งานของโรงพยาบาล)

  1. กด + แจ้งปัญหาใหม่ กรอกผู้แจ้ง, หน่วยงาน, รายละเอียด, กลุ่มปัญหา, สถานะ และผู้รับปัญหา
  2. กด 🤖 AI แนะนำกลุ่มปัญหา / วิธีแก้ เพื่อให้ AI จัดกลุ่ม เรียบเรียงข้อความ และหาปัญหาที่คล้ายกันในอดีต
  3. เมื่อแก้แล้ว กรอก วิธีการแก้ไข, ผู้แก้ไข, วันที่แก้ไข — ใส่ผู้แก้ไขและวันที่ครบ สถานะจะเป็น “ดำเนินการแล้ว” เอง
  • 🤖 วางแชท LINE (AI) — วางข้อความแชทหรือเปิดไฟล์ .txt (เลือกช่วงแชทด้วยปุ่ม วันนี้ / 7 วัน / 30 วัน / ทั้งหมด / กำหนดเอง) ให้ AI แยกเป็นรายการปัญหา ตรวจแล้วบันทึกทีเดียว · หน้าตรวจทานกรอง ข้อมูลไม่ครบ / อาจซ้ำ / ตามสถานะได้ · เรื่องที่ไม่ครบมีแถบแดง เลือกหน่วยงาน / ผู้แจ้ง / กลุ่มปัญหา ที่ขาดในการ์ดได้เลย และติ๊กให้ใช้กับเรื่องอื่นที่ยังว่างพร้อมกัน · กดที่เรื่องเพื่อกางแก้ไขพร้อมแชทต้นทาง
  • 🖨️ พิมพ์รายงาน — รายงานสรุปปัญหาตามช่วงวันที่ พร้อมช่องลงนามบริษัทและโรงพยาบาล (A4 แนวนอน)
  • 🖼️ Dashboard — สร้างลิงก์แดชบอร์ดสรุปปัญหาให้โรงพยาบาลดูได้โดยไม่ต้องล็อกอิน
  • ✍️ AI สรุปผู้แก้ไข — สรุปผลงานการแก้ปัญหาของแต่ละคนในช่วงเวลา · 📥 Excel ส่งออกรายการ

📄 แบบฟอร์ม

เช็คลิสต์แบบฟอร์มที่ต้องจัดทำ จัดเป็น “คลัง” แก้ไขในตารางได้ทันที (บันทึกอัตโนมัติ) พิมพ์ชื่อแล้วกด Enter เพื่อเพิ่ม หรือดึงจาก Template ด้วยปุ่ม 📐 สถานะ: ⚪ รอดำเนินการ · 🔵 กำลังดำเนินการ · ✅ ดำเนินการแล้ว

  • แถบกรอง (แถวเดียว) — ซ้าย: กรองตามสถานะ กดเลือก ยังไม่เสร็จ (ค่าเริ่มต้น — รวมรอดำเนินการ + กำลังดำเนินการ) · กำลังทำ · เสร็จแล้ว · ทั้งหมด ตัวเลขคือจำนวนรายการตามตัวกรองที่เลือกอยู่ · กลาง: ช่องค้นหา หาได้ทั้งชื่อแบบฟอร์ม ชื่อตามสัญญา และชื่อผู้จัดทำ กด × เพื่อล้างคำค้น · ขวา: ปุ่มตัวกรอง คลัง · ประเภท · ผู้จัดทำ ตัวที่กรองอยู่เป็นสีม่วงพร้อม × ล้างเฉพาะตัวนั้น · กรองตั้งแต่ 2 อย่างขึ้นไปมีปุ่ม ล้างทั้งหมด (สถานะคงเดิม)
  • ย่อ/ขยายคลัง — กดลูกศรหน้าชื่อคลัง หัวคลังแสดง “เสร็จ x/y” และแถบความคืบหน้า · ปุ่ม 🗑️ ลบคลัง/ลบแบบฟอร์ม จะโผล่เมื่อชี้เมาส์ที่แถวนั้น (กันกดพลาด)
  • ปุ่มขั้นถัดไปในแถว — ข้างสถานะมีปุ่ม เริ่มทำ (เมื่อรอดำเนินการ) และ เสร็จแล้ว (เมื่อกำลังดำเนินการ) กดครั้งเดียวเปลี่ยนสถานะได้ทันทีไม่ต้องเปิดดรอปดาวน์ · เปลี่ยนเป็นกำลังดำเนินการ/ดำเนินการแล้วตอนที่ยังไม่มีวันที่รับเอกสาร ระบบลงวันที่รับเป็น วันนี้ ให้อัตโนมัติ (แก้วันได้ภายหลัง)
  • เลิกทำ — หลังเปลี่ยนสถานะด้วยปุ่มขั้นถัดไป แก้หลายรายการ มอบหมายทั้งคลัง หรือเพิ่มใบที่ขาด จะมีแถบด้านล่างจอพร้อมปุ่ม เลิกทำ ประมาณ 8 วินาที กดเพื่อย้อนกลับเป็นค่าเดิมทั้งหมด
  • มอบหมายทั้งคลัง — ที่หัวคลังเลือก 👤 มอบหมายทั้งคลัง… แล้วเลือกพนักงาน ระบบตั้งผู้จัดทำให้ทุกแบบฟอร์มในคลังนั้นทีเดียว (หรือเลือก “ล้างผู้จัดทำทั้งคลัง”)
  • แก้หลายรายการพร้อมกัน — ชี้ที่ลำดับหน้าแถวแล้วติ๊กเลือก (หรือติ๊กที่หัวตารางเพื่อเลือกทั้งคลัง) จะมีแถบ “เลือก n รายการ” ให้กด เริ่มทำทั้งหมด / เสร็จทั้งหมด หรือเลือก เปลี่ยนสถานะ… / มอบหมายผู้จัดทำ… / 📥 วันที่รับ… / ✅ วันที่เสร็จ… (ตั้งวันที่เสร็จแล้วรายการที่ยังไม่เสร็จจะเปลี่ยนเป็นดำเนินการแล้วให้) ทีเดียว หรือกด 🗑️ ลบที่เลือก เพื่อลบทุกรายการที่เลือก (ยืนยันก่อนลบ · เฉพาะผู้มีสิทธิ์ลบ)
  • คอลัมน์ประเภท — ป้ายสีหน้าชื่อแบบฟอร์ม: ตั้งต้น · ตามสัญญา (ถ้าผูกชื่อตามสัญญาแล้วแสดงเป็น สัญญา ข้อ n ตามเลขในสัญญา) · ใหม่ — กดที่ป้ายเพื่อเปลี่ยนประเภท
  • คอลัมน์รับ → เสร็จ — บรรทัดเดียว: วันที่รับเอกสาร (คลิกเพื่อเลือกวัน) → วันที่ดำเนินการแล้ว (ระบบลงวันนี้ให้เมื่อสถานะเป็นดำเนินการแล้ว · คลิกเพื่อเลือกวันเองได้ · ถอยสถานะกลับ วันที่เสร็จจะถูกล้าง)
  • ชื่อตามสัญญา — ใช้เฉพาะประเภท แบบฟอร์มตามสัญญา: เปลี่ยนประเภทเป็นตามสัญญาแล้ว 🤖 AI จะจับคู่ชื่อตามสัญญาจาก Template แถบตามสัญญา (เฉพาะใบที่ยังไม่มีใครในโครงการใช้) ให้อัตโนมัติ · ถ้า AI หาไม่เจอ ชี้ที่แถวแล้วกด + ชื่อตามสัญญา เพื่อพิมพ์เอง หรือ 🤖 ให้ AI จับคู่ อีกครั้ง · ผูก 1 ต่อ 1: ชื่อตามสัญญา 1 ชื่อผูกได้กับแบบฟอร์มเดียวในโครงการ — พิมพ์ชื่อที่ใบอื่นใช้อยู่ ระบบจะเตือนและไม่บันทึก, ตอนดึงจาก Template ใบที่ผูกแล้วติ๊กไม่ได้, เลือกประเภทตามสัญญาให้แบบฟอร์มชื่อเดียวกันในคลังอื่นอีก ระบบขึ้นหน้าต่างเตือนว่ามีแบบฟอร์มตามสัญญาแล้วที่คลังไหน และประเภทกลับเป็นค่าเดิม · ประเภทอื่นไม่มีช่องชื่อตามสัญญา (เปลี่ยนจากตามสัญญาเป็นประเภทอื่น ชื่อตามสัญญาจะถูกล้าง และไปอยู่ส่วน “แบบฟอร์มเพิ่มเติม” ในใบส่งมอบ)
  • 📐 Template — รายชื่อเอกสารตั้งต้น แยก 2 แถบไม่ปนกัน: 📋 แบบฟอร์มมาตรฐาน และ 📑 แบบฟอร์มตามสัญญา (คอลัมน์ ชื่อเอกสาร เช่น XE-INVENTORY-DEP-TRANS-1 | ชื่อแบบฟอร์มตามสัญญา เช่น 12. ใบเบิกสินค้าระหว่างคลังย่อย — เพิ่มด้วยชื่อเอกสาร แล้วคลิกกรอกชื่อตามสัญญาในแถว) — เพิ่มในแถบไหนก็เป็นชนิดนั้น (กรอกชื่อแล้วกด Enter) คลิกที่ชื่อเพื่อแก้ไข (ห้ามว่าง/ห้ามซ้ำในแถบเดียวกัน · แบบฟอร์มที่ดึงไปใช้ในโครงการแล้วไม่เปลี่ยนตาม) มีช่อง 🔍 ค้นหา · ตอนดึงไปใช้ติ๊กได้ทั้ง 2 แถบในครั้งเดียว: มาตรฐาน → ประเภท “แบบฟอร์มตั้งต้น”, ตามสัญญา → ประเภท “แบบฟอร์มตามสัญญา” พร้อมชื่อตามสัญญาติดไปด้วย
  • Template แยกตามประเภทโครงการ — 1 Template ผูกได้ 1 ประเภทโครงการ หรือเป็น ใช้ร่วมทุกประเภท · หน้าจัดการมีรายการประเภทด้านซ้าย (มือถือเป็นแถบเลื่อนด้านบน) กดเลือกประเภทเพื่อดูเฉพาะประเภทนั้น — พิมพ์ชื่อเพิ่มตอนเลือกประเภทไหนอยู่ Template ใหม่จะผูกกับประเภทนั้น (เลือก “ทั้งหมด” = ใช้ร่วม) · ย้ายประเภทได้จากช่อง ประเภทโครงการ ท้ายแถว หรือชี้ที่เลขลำดับแล้วติ๊กหลายรายการ (หรือติ๊กหัวกลุ่ม) แล้วเลือก ย้ายไปประเภท... · ชื่อเอกสารห้ามซ้ำกับรายการที่โครงการเดียวกันเห็นพร้อมกัน (ประเภทเดียวกัน หรือใช้ร่วม) · ตอนดึงไปใช้ แสดงเฉพาะ Template ของประเภทโครงการนั้น + ใช้ร่วม แยกเป็นกลุ่ม ติ๊กหัวกลุ่มเพื่อเลือกทั้งกลุ่ม ติ๊ก แสดงประเภทอื่นด้วย เมื่อต้องการยืมจากประเภทอื่น (โครงการที่ยังไม่ระบุประเภทเห็นเฉพาะใช้ร่วม) · แถบตามสัญญา n/N และ AI จับคู่ชื่อตามสัญญา ใช้เฉพาะ Template ของประเภทโครงการนั้น + ใช้ร่วม
  • แถบแบบฟอร์มตามสัญญา — บรรทัดเดียวเหนือรายการคลัง เทียบโครงการกับชุดใน Template แถบตามสัญญา บอกว่า “ยังขาด n ใบ (มี x จาก y)” · กด ดูว่าใบไหน เพื่อดูรายชื่อใบที่ขาด · ✨ ผูกชื่อตามสัญญา ให้แบบฟอร์มที่ชื่อเอกสารตรงแต่ยังไม่มีชื่อตามสัญญา · เลือกคลัง (ถ้ามีหลายคลัง) และผู้จัดทำ (ตั้งให้เป็นคนที่ถือแบบฟอร์มในโครงการมากที่สุดไว้แล้ว) แล้วกด + เพิ่มทั้ง n ใบ ได้ครบในคลิกเดียว · ครบแล้วเหลือแถบเขียว ✅ แบบฟอร์มตามสัญญาครบ
  • 📄 ใบส่งมอบ — สร้าง “ใบส่งมอบฟอร์มในระบบ” จากรายการในโครงการทันที ไม่ต้อง copy ไปทำ Excel เอง: แบบฟอร์มที่มีชื่อตามสัญญา = ส่วนตามสัญญา (เรียงตามเลขสัญญา 1, 2, 3…), ไม่มีชื่อตามสัญญา = “แบบฟอร์มเพิ่มเติม” · ถ้าตามสัญญายังไม่ครบ ระบบเตือนก่อนพิมพ์ · ผู้ดำเนินการ/วันที่แล้วเสร็จดึงจากผู้จัดทำ/วันที่ดำเนินการ · กรอกหัวเรื่อง ผู้ลงนาม 2 ฝั่ง (ระบบจำไว้ต่อโครงการ) — ผู้ลงนามฝั่ง BMS ตั้งต้นเป็นเจ้าของไซต์ของโครงการพร้อมตำแหน่ง เปลี่ยนได้โดยพิมพ์ค้นหา/เลือกจากรายชื่อพนักงาน (ตำแหน่งเติมให้อัตโนมัติ) หรือกดปุ่ม ↺ ใช้เจ้าของไซต์ มุมขวาของการ์ดฝั่ง BMS เพื่อกลับเป็นค่าตั้งต้น (การ์ดผู้ลงนามแยกสี: ซ้าย = ผู้ส่งมอบ BMS, ขวา = ผู้รับมอบ สถานพยาบาล) · ฝั่งสถานพยาบาลกด 👥 ผู้ติดต่อ รพ. เพื่อใช้ชื่อ/ตำแหน่งจากผู้ติดต่อที่บันทึกไว้ในข้อมูลสถานพยาบาล — มีหลายคนจะขึ้นรายการให้เลือก (ปุ่มแสดงเมื่อ รพ. ของโครงการมีผู้ติดต่อ) · ช่องหน่วยงานฝั่ง BMS ตั้งต้นเป็น “บริษัท บางกอก เมดิคอล ซอฟต์แวร์ จำกัด” แก้ได้ · เลือกเฉพาะที่ดำเนินการแล้วได้ แล้วกด 🖨️ พิมพ์ / PDF (A4 แนวนอน) หรือ 📥 Excel

🎓 อบรม · 📅 Calendar · 📈 Report · 🖨️ พิมพ์เอกสาร

  • อบรม — จัดการการอบรมของโครงการ (ดู ระบบอบรม)
  • Calendar — ปฏิทินงานตามวันครบกำหนด
  • Report — สรุปงานเสร็จ/ล่าช้า/ครบกำหนด 14 วัน/ปัญหา/แบบฟอร์ม พร้อม ✨ สรุปด้วย AI, 📥 Excel และ 📷 บันทึกเป็นรูปภาพ
  • พิมพ์เอกสาร — พิมพ์ใบลงชื่อ (เช่น Stand by, ประชุมสรุป Flow, SIT) เลือกหัวข้อ วันที่ จำนวนแถว และผู้ลงนาม แล้วกด 🖨️ พิมพ์เอกสาร (ต้องอนุญาต Popup ในเบราว์เซอร์)

📐 Template

กด + สร้าง Template หน้าต่างแบ่ง 2 ฝั่ง: ซ้าย = ชื่อ/ประเภท/รายละเอียด + ตัวช่วย · ขวา = โครงสร้าง Phase / Task / เช็คลิสต์ ลาก ⠿ เพื่อเรียงลำดับ กด 💾 บันทึก Template (หรือ Ctrl+S) หรือสร้างจากโครงการที่มีอยู่ด้วย 📐 บันทึกเป็น Template

  • เพิ่ม Task เร็ว — พิมพ์ในช่อง พิมพ์ชื่อ Task แล้วกด Enter ท้ายแต่ละ Phase แล้วพิมพ์ตัวถัดไปต่อได้ทันที · วางข้อความหลายบรรทัดในช่องนี้ = เพิ่มหลาย Task ในครั้งเดียว (ช่องเช็คลิสต์ก็ทำแบบเดียวกันได้) · ใส่ (3) ท้ายชื่อ = จำนวนวัน · Enter ในชื่อ Task = ไปแถวถัดไป · Ctrl+D = ทำซ้ำแถวนั้น
  • จำนวนวัน — ไม่บังคับ เว้นว่าง = ระบบประเมินจากชื่องาน (แสดงเป็นตัวจาง เช่น ~3ว.) · ด้านซ้ายและท้ายหน้าต่างสรุปจำนวน Phase / Task / เช็คลิสต์ / วันทำงานรวม ให้ทันทีที่แก้
  • Task ที่ใช้บ่อย — ชิปด้านซ้าย (ดึงจากชื่อ Task ที่ซ้ำกันใน Template อื่น) คลิกเพื่อเพิ่มเข้า Phase ที่กำลังทำอยู่ (กรอบสีม่วง — คลิก Phase ไหนก็เปลี่ยนเป็น Phase นั้น)
  • 📋 วางเป็นข้อความ — สลับโหมดด้านบนขวา แล้ววางรายการจาก Excel / Word / LINE: บรรทัดปกติ = Phase · ขึ้นต้นด้วย - = Task · ย่อหน้า (Tab) แล้ว - = เช็คลิสต์ · ดูตัวอย่างผลลัพธ์ทางขวาก่อนกด ✓ ใช้โครงสร้างนี้ (สลับกลับแบบรายการ/บันทึก ระบบใช้ข้อความที่แก้ให้อัตโนมัติ)
  • เริ่มเร็วขึ้น — เลือก 📋 คัดลอกโครงสร้างจาก Template… หรือ 🏗️ ดึงโครงสร้างจากโครงการ… ด้านซ้าย (ถ้ามีโครงสร้างอยู่แล้วจะเพิ่มต่อท้าย ไม่ทับของเดิม) · ปุ่ม ⧉ ที่หัว Phase = ทำซ้ำทั้ง Phase พร้อม Task และเช็คลิสต์ · ▾ = พับ/ขยาย Phase
  • ร่างอัตโนมัติ — ระหว่างแก้ ระบบเก็บร่างไว้ในเครื่องให้ (ท้ายหน้าต่างขึ้น ✓ บันทึกร่างอัตโนมัติ) ปิดหน้าต่างหรือรีเฟรชโดยไม่ตั้งใจ เปิดใหม่จะมีแถบ กู้คืนร่าง / ทิ้ง
  • บันทึก แล้วสร้างโครงการ — บันทึก Template แล้วเปิดหน้าต่างเพิ่มโครงการโดยเลือก Template นี้ไว้ให้
  • ผูกประเภทโครงการ — กดปุ่มประเภทในหน้าต่าง Template (ว่าง = ใช้ร่วมทุกประเภท) · บันทึกเป็น Template จากโครงการ ระบบตั้งประเภทตามโครงการให้
  • หน้า Template จัดเป็นกลุ่มตามประเภทโครงการ (สีตามประเภท) กดหัวกลุ่มเพื่อพับ/ขยาย · กดชิปด้านบนเพื่อดูทีละประเภท หรือพิมพ์ในช่อง 🔍 ค้นหา (ค้นชื่อ Phase ได้ด้วย) · 1 Template = 1 แถว เห็นชื่อ Phase เรียงตามลำดับ และจำนวน Phase/Task · คลิกแถวหรือ ✏️ เพื่อแก้ · 🗑 เพื่อลบ
  • เปลี่ยนประเภท — คลิกแถวหรือ ✏️ แล้วเลือกช่อง ประเภทโครงการ ในหน้าต่างแก้ไข
  • ✨ จัดกลุ่มอัตโนมัติ — ถ้ามี Template ที่ยังไม่ผูกประเภท ระบบเดาประเภทจากโครงการต้นทาง (คำอธิบาย “สร้างจากโครงการ …”) หรือจากชื่อประเภทที่อยู่ในชื่อ Template แล้วแสดงรายการให้ยืนยันก่อนบันทึก

ระบบอบรม

เมนู Workspace › ระบบอบรม (ภาพรวม/ตั้งค่ากลาง) และ ติดตามสถานะโครงการ › แท็บ 🎓 อบรม (รายโครงการ)

เมนูระบบอบรม (ส่วนกลาง)

  • ภาพรวมผลการอบรม — จำนวนรอบ ผู้ลงทะเบียน ผู้เข้าอบรม คะแนนประเมิน ผลสอบ รายโครงการ และรอบอบรม 14 วันข้างหน้า กดแถวเพื่อเปิดการอบรมของโครงการ
  • หลักสูตรอบรม, คลังแบบทดสอบ, ใบประกาศ & อีเมล — ตั้งค่ากลางที่ใช้ทุกโครงการ (เห็นเฉพาะผู้มีสิทธิ์เพิ่ม/แก้/ลบ)
  • สิทธิ์แยก 2 แถว (Admin Panel › สิทธิ์การใช้งาน): ระบบอบรม = เมนูนี้และตั้งค่ากลาง · ติดตามสถานะโครงการ › อบรม = แท็บ 🎓 อบรม ของโครงการ (ดู = เข้าแท็บ · เพิ่ม = เปิดอบรม/นำเข้าข้อมูล · ลบ = เคลียร์ข้อมูล/ปิดอบรม)

เปิดอบรมให้โครงการ

  1. ไปที่ ติดตามสถานะโครงการ › เลือกโครงการ › แท็บ 🎓 อบรม
  2. กด เปิดอบรม (โครงการต้องระบุโรงพยาบาลในเมนูโครงการก่อน) ระบบจะออกรหัสไซต์ให้ — ผู้กดต้องเป็น PM/อยู่ในทีมโครงการ และมีสิทธิ์ เพิ่ม ของแถว ติดตามสถานะโครงการ › อบรม (หรือเป็น Admin) · ถ้ายังเปิดไม่ได้ หน้านี้จะบอกว่าขาดอะไร
  3. ที่ 📅 รอบอบรม กด เพิ่มรอบ ระบุหลักสูตร วันที่ เวลา สถานที่ วิทยากร และจำนวนที่นั่ง
  4. ที่ 🔗 ลงทะเบียน คัดลอกลิงก์หรือบันทึกรูป QR ส่งให้ผู้เข้าอบรม (ปุ่ม ร่างข้อความเชิญ ให้ AI ร่างข้อความเชิญได้)
  5. วันอบรม ใช้ 📷 เช็คชื่อ สแกน QR ของผู้เข้าอบรม พิมพ์ชื่อ หรือเพิ่ม Walk-in
  6. หลังอบรม ส่งลิงก์ 📝 แบบประเมิน และแบบทดสอบ แล้วดูผลที่ ⭐ ผลประเมิน, 📊 Analytics และ ✏️ ผลสอบ & ใบประกาศ

เมนูอื่นในการอบรมของโครงการ

  • 👥 ผู้ลงทะเบียน — ค้นหา เพิ่ม นำเข้าจาก Excel/CSV และ พิมพ์แบบฟอร์ม ใบลงชื่อ
  • 📋 ตรวจสอบรายชื่อ, 🛡️ ตรวจสอบสิทธิ์ (มี Login แล้ว/ไม่มี Login/ปิดการใช้งาน — กดป้ายสรุปด้านบนเพื่อกรองตามสถานะ · เปิดหน้าแล้วข้อมูลล่าสุดมาเอง · แก้แล้วยังไม่บันทึกกด "ยกเลิกการแก้ไข" ได้), 🔢 ตรวจสอบคีย์ยอด (คีย์ยอดตั้งต้น BMS-INVENTORY รายแผนก)
  • ผลสอบ & ใบประกาศ — ส่งใบประกาศซ้ำ เพิกถอน/คืนสถานะ หรือลบผลสอบ (คืนสิทธิ์สอบ 1 ครั้ง)
  • 📚 ข้อมูลพื้นฐาน — รายการสถานที่ แผนก คำนำหน้า และวิทยากร · ⚙️ ตั้งค่าโครงการ
  • 📖 คู่มือ — คู่มือละเอียดของระบบอบรม

คลังแบบทดสอบ

สร้างชุดข้อสอบ กำหนดจำนวนข้อ เกณฑ์ผ่าน เวลา และจำนวนครั้งที่สอบได้ เพิ่มข้อสอบเอง ให้ AI ร่างข้อสอบ หรือนำเข้า Excel (กด ส่งออก ได้ไฟล์แม่แบบพร้อม รหัสข้อ — แก้ในไฟล์แล้ว นำเข้า กลับ ข้อเดิมจะถูกอัปเดตทับไม่ซ้ำ · แถวที่รหัสข้อว่างจะเพิ่มเป็นข้อใหม่) ข้อที่มีผู้สอบแล้วแก้ข้อความได้ แต่ถ้าเปลี่ยนเฉลยหรือจำนวนตัวเลือก ระบบจะปิดข้อเดิมแล้วเพิ่มเป็นข้อใหม่ ชุดที่มีผลสอบแล้วลบไม่ได้ (ปิดใช้งานแทน) ผู้สอบผ่านจะได้รับใบประกาศทางอีเมลอัตโนมัติ

Timesheet

เมนู ต้นทุน › Timesheet (ดูและวิเคราะห์ ไม่ต้องกรอกเอง)

ชั่วโมงงานสร้างให้อัตโนมัติจากทีมงาน/รอบเข้าไซต์ของโครงการ = วันทำงาน × 8 ชั่วโมง โดยไม่นับเสาร์-อาทิตย์ วันหยุด และวันลาของคนนั้น เมื่อแก้โครงการ Timesheet จะอัปเดตตามเอง

ตัวกรอง: ค้นหา, ปี, เดือน, ประเภท, โครงการ, พนักงาน · การ์ดสรุป: ชั่วโมงที่จัดสรร, Utilization ทีม, งานเกินกำลัง/ซ้อน, คนที่มีเวลาว่าง, วันลารวม

3 มุมมอง

  • 👥 ภาระงานรายคน — % การใช้เวลาของแต่ละคน (ค่าเริ่มต้นเรียงตามตำแหน่ง เปลี่ยนเป็น Utilization / ว่าง / ชั่วโมง / ชื่อ ได้ที่ช่อง “เรียง”) กดแถวเพื่อดูแยกโครงการและช่วงที่ถูกจัดงานซ้อน
  • 🗓 Heatmap รายเดือน — ตาราง คน × 12 เดือน กดช่องเพื่อกรองเดือน/คน
  • 📁 ตามโครงการ — ชั่วโมงและคน-วันของแต่ละโครงการ

ระดับการใช้เวลา: ใช้งานต่ำ <50% · ปานกลาง 50–84% · เหมาะสม 85–105% · เกินกำลัง >105% · ปุ่ม Excel ส่งออกตามมุมมองที่เปิดอยู่

ถ้าเห็นป้าย ⚠ วันที่ลงเป็น พ.ศ. แปลว่าบางโครงการกรอกปีเป็น พ.ศ. ระบบแปลงให้แล้ว แต่ควรแก้ที่ตัวโครงการ

  • กด ▶ (ข้างลูกศร) เพื่อเล่นอัตโนมัติ เลื่อนไปคนถัดไปทุก 5 วินาที กด ⏸ เพื่อหยุด · กดลูกศรเองระหว่างเล่น = เริ่มนับเวลาใหม่ · หยุดชั่วคราวเองตอนเปิดหน้าต่างแก้ไขหรือสลับไปแท็บอื่น
  • กด ⛶ เต็มจอ เพื่อขึ้นจอนำเสนอ — เริ่มเล่นอัตโนมัติให้ทันที เหมาะเปิดค้างไว้บนจอทีวี (กด Esc เพื่อออก)
  • กด 🔇 (ข้างปุ่มเล่น) ให้เป็น 🔊 เพื่อเปิด เสียงแนะนำตัว — กลับไปเริ่มที่คนที่ 1 เสมอ แล้วเสียง AI พูดคำทักทายของทีม (ถ้าตั้งไว้) ตามด้วย “คนที่ 1 คุณ<ชื่อเล่น> <ชื่อจริง>” หัวข้อ/ตำแหน่ง แผนก และคำแนะนำ (แก้คำพูดได้ — ดูหัวข้อ “ตั้งค่าคำพูด AI” ด้านล่าง) พูดจบเลื่อนไปคนถัดไปเองจนถึงคนสุดท้าย พูดคำปิดท้าย แล้วปิดเสียงอัตโนมัติ · กดเลื่อนเองหรือเปลี่ยนทีมระหว่างนั้น = แนะนำคนนั้นแทน (เปลี่ยนทีม = ทักทายทีมใหม่ แล้วเริ่มคนที่ 1) · กด 🔊 อีกครั้งเพื่อหยุด
  • คนที่ยังไม่มีรูปจะแสดงเป็นเงาคนพร้อมชื่อเล่น
  • รูปของคุณในคลังรูปทีมจะแสดงเป็นรูปโปรไฟล์ที่มุมล่างซ้ายของแถบเมนูด้วย (ยังไม่มีรูป = แสดงตัวอักษรแรกของชื่อ)

🔗 แชร์ลิงก์ไปใส่สไลด์นำเสนอ

  1. เลือกทีม แล้วกด 🔗 แชร์ลิงก์ — ครั้งแรกต้องเป็นผู้มีสิทธิ์แก้จึงจะสร้างลิงก์ได้ (สร้างแล้วผู้มีสิทธิ์ดูก็คัดลอกได้)
  2. เลือกตัวเลือก: เล่นอัตโนมัติ (เลื่อนคนถัดไปทุก 5 วินาที เปิดไว้เป็นค่าเริ่มต้น) · 🔊 เปิดเสียงแนะนำตัวทันที (เสียง AI แนะนำทีละคนตามคำพูดที่ตั้งไว้ของทีม — เบราว์เซอร์ไม่ให้เล่นเสียงเอง ต้องแตะจอ/กดปุ่มใดก็ได้ 1 ครั้งก่อน หน้าจอจะขึ้นบอก) · ซ่อนปุ่มควบคุม (ภาพสะอาด เหมาะฝังในสไลด์)
  3. กด 📋 คัดลอก แล้วนำไปใส่สไลด์ — ใส่เป็นลิงก์ (คลิกแล้วเปิดเบราว์เซอร์) หรือฝังหน้าเว็บในสไลด์ เช่น PowerPoint ส่วนเสริม Web Viewer, Canva › ฝัง · กด ↗ เปิดดู เพื่อดูหน้าที่คนอื่นจะเห็น
  • ใครมีลิงก์เปิดดูได้ทันทีโดยไม่ต้อง login (ดูได้อย่างเดียว แก้ไม่ได้) · แสดงชื่อ ชื่อเล่น ตำแหน่ง แผนก หัวข้อ และคำแนะนำ — ไม่แสดงอีเมล/เบอร์โทร
  • แต่ละทีมมีลิงก์ของตัวเอง · แก้สมาชิก/รูป/คำแนะนำเมื่อไร ลิงก์เห็นของใหม่ทันที (รีเฟรชหน้า)
  • ในหน้าลิงก์: กดลูกศร / ปัดซ้าย-ขวา / ปุ่ม ← → PageUp PageDown (รีโมตพรีเซนต์ใช้ได้) เพื่อเลื่อนคน · กด 🔇 หรือ V เพื่อเปิด/ปิดเสียงแนะนำตัว · กดปุ่ม ⛶ ท้ายแถวปุ่มควบคุม, F หรือดับเบิลคลิกตรงไหนก็ได้ (ใช้ได้แม้ซ่อนปุ่มควบคุม) เพื่อเต็มจอ กดซ้ำหรือ Esc เพื่อออก · ถ้าฝังในสไลด์แล้วโปรแกรมไม่อนุญาตเต็มจอ จะเปิดหน้านี้ในแท็บใหม่แทน
  • ไม่อยากให้ลิงก์เดิมใช้ได้อีก กด 🔄 สร้างลิงก์ใหม่ (ผู้มีสิทธิ์แก้) — ลิงก์เดิมที่แชร์/ใส่สไลด์ไว้จะเปิดไม่ได้ทันที

สร้าง/แก้ไขทีม (ผู้มีสิทธิ์เพิ่ม/แก้)

  1. กด + ทีมใหม่ หรือ ✏️ แก้ไขทีม
  2. ตั้งชื่อทีม และตัวอักษรใหญ่ด้านหลัง (ภาษาอังกฤษ เช่น OUR TEAM, IMPLEMENT)
  3. เพิ่มสมาชิกจากช่อง + เพิ่มคน หรือทั้งแผนก… ด้านซ้าย (พิมพ์ค้นหาได้) — เลือกชื่อคนเพื่อเพิ่มทีละคน หรือเลือก ทั้งแผนก … เพื่อเพิ่มทุกคนในแผนกนั้น (คนหนึ่งอยู่ได้หลายทีม)
  4. รายชื่อสมาชิกอยู่ด้านซ้าย (เรียงตามตำแหน่งอัตโนมัติ) ใต้ชื่อมีป้าย รูป · คำแนะนำ · บทพูด — สีเขียว = ใส่แล้ว สีเทา = ยังว่าง
  5. กดที่ชื่อเพื่อแก้รายละเอียดด้านขวา: ใส่/เปลี่ยนรูป หัวข้อใหญ่ (ว่าง = ใช้ชื่อตำแหน่ง) คำแนะนำสั้น ๆ สีพื้นหลัง (กดวงสี หรือ สีอื่น…) และบทพูด AI เฉพาะคน (กด ▶ ลองฟังคนนี้ ได้) · ใช้ ← คนก่อน / คนถัดไป → ไล่แก้ทีละคน
  6. เอาคนออกด้วยปุ่ม เอา … ออกจากทีม ท้ายแผงขวา แล้วกด บันทึก

🔊 ตั้งค่าคำพูด AI

ในหน้าต่าง ✏️ แก้ไขทีม กดเปิดส่วน 🔊 คำพูด AI แนะนำตัว (ตั้งแยกได้แต่ละทีม)

  • คำทักทาย — พูดก่อนแนะนำคนแรก เช่น “สวัสดีค่ะ ขอแนะนำสมาชิก{ทีม} ทั้งหมด {จำนวน} คนค่ะ” · ว่าง = ไม่พูด
  • แม่แบบแนะนำแต่ละคน — ใช้กับทุกคนในทีม ค่าเริ่มต้นคือ “คนที่ {ลำดับ} คุณ{ชื่อเล่น} [{ชื่อจริง}]” / “[{หัวข้อ}] [แผนก {แผนก}]ค่ะ” / “{คำแนะนำ}ค่ะ” (คำแนะนำที่พิมพ์ “ค่ะ” ไว้แล้วจะไม่พูดซ้ำ) · กด คืนค่าเริ่มต้น เพื่อกลับไปใช้แบบเดิม
  • คำปิดท้าย — พูดต่อจากคนสุดท้าย เช่น “ขอบคุณค่ะ” · ว่าง = ไม่พูด
  • บทพูดเฉพาะคน — ช่อง 🔊 ใต้คำแนะนำของแต่ละคน ถ้าพิมพ์ไว้จะใช้แทนแม่แบบสำหรับคนนั้น (ว่าง = ใช้แม่แบบทีม)
  • ช่องข้อมูลที่ใช้ได้: {ลำดับ} {ชื่อเล่น} {ชื่อจริง} {หัวข้อ} {ตำแหน่ง} {แผนก} {คำแนะนำ} {ทีม} {จำนวน} — คำทักทาย/ปิดท้ายใช้ได้แค่ {ทีม} {จำนวน} · {ชื่อจริง} จะว่างถ้าเหมือนชื่อเล่น (ไม่พูดซ้ำ)
  • ขึ้นบรรทัดใหม่ = เว้นจังหวะ · ครอบด้วย [ ] = ถ้าข้อมูลข้างในว่างจะข้ามทั้งวงเล็บ เช่น [แผนก {แผนก}] คนที่ไม่มีแผนกจะไม่พูดคำว่า “แผนก” ลอย ๆ
  • ติ๊ก ลงท้ายทุกบรรทัดด้วย “ค่ะ” (ด้านบนของส่วนนี้ เปิดไว้เป็นค่าเริ่มต้น) — เติม “ค่ะ” ท้ายบรรทัดที่ยังไม่ได้ลงท้ายด้วย ค่ะ / คะ / ครับ / นะ ในช่องคำทักทาย แม่แบบ และคำปิดท้ายให้เห็นทันที รวมถึงบทพูดเฉพาะคนตอนพูด (ยกเว้นบรรทัดที่จบด้วยชื่อคน เช่น “คุณ{ชื่อเล่น} [{ชื่อจริง}]” จะไม่ต่อ “ค่ะ” ท้ายชื่อ) เพราะเสียง AI ชอบตัดพยางค์สุดท้ายของประโยค (เช่น ชำนาญการพิเศษ) แนะนำให้เปิดไว้ · ถ้าปิด ให้ลงท้ายแต่ละบรรทัดเอง
  • กด ▶ ลองฟัง เพื่อฟังคำทักทาย + คนแรกจากค่าที่กำลังแก้ได้ก่อนบันทึก

🖼️ คลังรูปทีม

แท็บ 🖼️ คลังรูปทีม (ผู้มีสิทธิ์แก้) รวมพนักงานทุกคนพร้อมสถานะรูป พนักงาน 1 คนมีรูปได้ 1 รูป ใช้ร่วมกันทุกทีม

  • กด ⬆️ อัปโหลด / 🔄 เปลี่ยนรูป / 🗑️ ที่การ์ดของแต่ละคน หรือกด ⬆️ ใส่รูป ในหน้าต่างแก้ไขทีม
  • รูปที่ใช้ได้ดี: PNG พื้นหลังโปร่งใส แนวตั้ง 3:5 (เช่น 1200×2000) ตัวการ์ตูนเต็มตัว เท้าชิดขอบล่าง ไม่เกิน 5MB (รองรับ PNG, WebP, JPG — JPG ไม่มีพื้นใส)
  • พื้นลายตารางหมากรุกในการ์ด = ส่วนที่โปร่งใส ใช้ตรวจว่าลบพื้นหลังเรียบร้อยแล้ว
  • ติ๊ก เฉพาะคนที่ยังไม่มีรูป เพื่อดูว่ายังขาดใคร

✨ สร้างตัวการ์ตูนจากรูปถ่ายด้วย AI

  1. กด ✨ Prompt สร้างตัวการ์ตูน แล้วเลือกแนว (ฟิกเกอร์ไวนิล, ดินน้ำมัน, อนิเมะ 3D, ตุ๊กตาผ้า, ตัวละครเกม, ซูเปอร์ฮีโร่, ไม้แกะสลัก, สติกเกอร์ 2D) หรือพิมพ์แนวที่อยากได้แล้วกด ✨ ให้ AI คิดแนวใหม่ (ว่างไว้ = AI สุ่มให้) — ทุกแนวล็อกขนาด 3:5 เต็มตัว พื้นใส เหมือนกัน
  2. กด 📋 คัดลอก Prompt คนแรก
  3. เปิด ChatGPT / Gemini / Copilot ที่สร้างรูปได้ แนบรูปถ่ายหน้าตรงของพนักงาน วาง Prompt แล้วแก้ส่วนใน [ ] (ชุด, อุปกรณ์ตามตำแหน่ง)
  4. คนถัดไปใช้แชทเดิมกับ Prompt "คนถัดไป" เพื่อให้สไตล์เหมือนกันทั้งทีม
  5. ถ้าได้พื้นขาว ลบพื้นหลังที่ remove.bg หรือ Canva บันทึกเป็น PNG แล้วอัปโหลดในคลังรูปทีม
ขออนุญาตเจ้าตัวก่อนนำรูปถ่ายไปให้ AI ภายนอกสร้างตัวการ์ตูน

แผนที่ทีม

เมนู ทีม › แผนที่ทีม

แผนที่ประเทศไทย 3 มิติ ดูว่าเดือนนี้ทีมลงพื้นที่จังหวัดไหน ใครไปโรงพยาบาลไหน และเดินทางเส้นทางไหน ข้อมูลมาจาก โครงการ (โรงพยาบาลของโครงการ + ทีมงานและช่วงวันของแต่ละคน + รอบเข้าไซต์) จับคู่กับ จังหวัด/พิกัดของโรงพยาบาล

  • จังหวัดที่มีงาน ยกสูงและเป็นสีส้ม — ยิ่งมีคน·วันมากยิ่งสูงและเข้ม · ชี้เมาส์ที่จังหวัดเพื่อดูว่าใครไป รพ. ไหน วันไหน
  • เลื่อนเดือน — แถบเดือนด้านล่าง ม.ค.–ธ.ค. (แท่งเล็กบอกปริมาณงานแต่ละเดือน) ปุ่ม ‹ › สองข้างแถบเดือนใช้เลื่อนทีละปี (หรือกดลูกศรซ้าย/ขวาบนคีย์บอร์ดเพื่อเลื่อนทีละเดือน) · กรองตามแผนกได้
  • ทั้งปี — ปุ่มท้ายแถบเดือน รวมงานทั้งปีบนแผนที่เดียว (จังหวัด เส้นทาง ระยะทางรวมทั้งปี) · ปุ่ม ‹ › สองข้างแถบเดือนเลื่อนทีละปี · เล่นรายวันไล่ทั้งปีในประมาณ 20 วินาที
  • เส้นทาง — เส้นโค้งสีประจำตัวแต่ละคน เริ่มที่สำนักงาน ไป รพ. ตามลำดับวัน แล้วกลับสำนักงาน (ว่างระหว่างงานเกิน 3 วัน ถือว่ากลับสำนักงาน)
  • เล่นรายวัน — กด ▶ หรือลากแถบวัน ป้ายชื่อแต่ละคนเคลื่อนไปตามวัน รายชื่อด้านซ้ายบอกว่าอยู่ที่ไหน/กำลังเดินทาง
  • รายชื่อทีมงาน — แสดงเฉพาะคนที่มีงานนอกสถานที่ในเดือนที่เลือก จัดกลุ่มตามแผนก (เรียงตามตำแหน่งในแต่ละแผนก)
  • คลิกชื่อคน — แผนที่และตัวเลขสรุปเปลี่ยนเป็นของคนนั้นคนเดียว (จังหวัด/รพ. ที่ไป คน·วัน ระยะทาง) · กดชื่อเดิมอีกครั้งหรือปุ่ม ดูทั้งทีม เพื่อกลับภาพทั้งทีม · แสดงเฉพาะเส้นทางของคนนั้น พร้อมลำดับจุด วันที่ และระยะทางแต่ละช่วง
  • หมุนแผนที่: ลากเมาส์ · ซูม: เลื่อนล้อเมาส์ · ปุ่ม รีเซ็ตมุมมอง กลับมุมเดิม · ปุ่ม เต็มจอ แสดงแผนที่เต็มหน้าจอ (กด Esc หรือ ออกจากเต็มจอ เพื่อกลับ)
รูปตึก = สำนักงาน (จุดเริ่ม/จบของทุกเส้นทาง) · หมุดสีขาว = รพ. ที่มีพิกัดจริง · หมุดสีเทา = ยังไม่มีพิกัด ระบบวางไว้กลางจังหวัด — เติมพิกัดได้ที่ รายชื่อ รพ. › เครื่องมือ › เติมพิกัด รพ. · ระยะทางเป็นเส้นตรงโดยประมาณ ไม่ใช่ระยะตามถนน · โครงการที่ไม่ได้ระบุโรงพยาบาลจะไม่แสดงบนแผนที่

บันทึกงาน

เมนู ทีม › บันทึกงาน

บันทึกงานที่ไม่ใช่โครงการ เช่น ประชุม อบรม สัมมนา ลงพื้นที่ต่างจังหวัด ดูงานต่างประเทศ บันทึกงานจะแสดงในปฏิทินทีม (แถบสีส้ม) และนับเป็น “ไม่ว่าง” ในหน้าทีมว่าง

หน้าต่างบันทึกแบ่งเป็น 5 ขั้น มีเลขกำกับ ไล่กรอกจากบนลงล่าง (ช่องที่มี * ต้องกรอก ที่เหลือข้ามได้):

  1. กด เพิ่มบันทึก
  2. ① ทำงานอะไร — พิมพ์ ชื่องาน (เคอร์เซอร์อยู่ที่ช่องนี้ให้แล้ว) หรือแตะงานในแถว ล่าสุด: ใต้ช่อง ระบบเติมชื่องาน หมวด และสถานที่ให้ครบ · แล้วเลือก หมวดงาน จากช่องรายการ ▾ (ระบบเดาหมวดให้จากชื่องาน มีป้าย แนะนำ เปลี่ยนเองได้)
  3. ② เมื่อไร — วันที่ตั้งเป็น วันนี้ ไว้ให้แล้ว · งานหลายวันติ๊ก หลายวัน (ข้างหัวข้อวันที่) แล้วใส่วันสิ้นสุด · ใส่ เวลา เริ่ม–เลิกได้ (ไม่บังคับ) ใส่เวลาเริ่มแล้วจะตั้ง 🔔 เตือนก่อนเริ่ม ได้
  4. ③ ที่ไหน — แตะเลือก สถานที่ (ในพื้นที่ / ต่างจังหวัด / ต่างประเทศ พร้อมปลายทาง) · ประชุมออนไลน์วาง ลิงก์ Zoom / Google Meet / Teams ได้ (ไม่บังคับ) การ์ดบันทึกงานจะมีปุ่ม 🎥 เข้าร่วม Zoom ให้กดเข้าห้องได้ทันที
  5. ④ รายละเอียดเพิ่มเติม (ไม่บังคับ) — จดสั้น ๆ แล้วกด ✨ เรียบเรียง ให้ AI เรียบเรียงให้ได้
  6. ⑤ ใครร่วมงานบ้าง — เพิ่ม ผู้เข้าร่วม ที่ฝั่งขวาของหน้าต่าง (มือถืออยู่ล่างสุด) โดยแตะชื่อในรายชื่อ (แบ่งตามแผนก) หรือพิมพ์ค้นหาชื่อ/ชื่อเล่น/แผนกแล้วกด Enter · คนที่เลือกจะขึ้นไปอยู่ด้านบนรายชื่อ กด ✕ หรือแตะชื่อในรายชื่ออีกครั้งเพื่อเอาออก · งานหลายวัน: แต่ละคนมีช่องวันเริ่ม–วันสิ้นสุดของตนเอง (ค่าเริ่มต้นตามวันของงาน) (ไม่เลือกใคร = บันทึกของตนเอง)
  7. กด Enter ในช่องชื่องาน (ครั้งแรก AI ช่วยกรอก · ครั้งที่สองบันทึก) หรือกด 💾 บันทึก · แก้ไขบันทึกเดิม กด Enter = บันทึกทันที
ลงงานหลายรายการติดกัน: ติ๊ก บันทึกแล้วเพิ่มงานถัดไปต่อ ที่ด้านล่างหน้าต่าง บันทึกแล้วหน้าต่างไม่ปิด ช่องชื่องานจะว่างให้พิมพ์งานถัดไป โดยคงวันที่ หมวด และสถานที่ไว้ (ระบบจำค่านี้ไว้ในเครื่อง)
ให้ AI ช่วยกรอก
  • กด Enter ให้ AI กรอก (หรือกด ✨ AI กรอกให้ ข้างหัวข้อชื่องาน) — พิมพ์งานเป็นประโยคเดียวในช่องชื่องาน เช่น “13-15 ต.ค. ลงพื้นที่ติดตั้งคลังสินค้า รพ.ขอนแก่น กับเอี้ยม เต้ย” แล้วกด Enter AI จะแยกเป็นชื่องาน วันที่ (ติ๊กหลายวันให้) สถานที่/ปลายทาง หมวด และเพิ่มผู้เข้าร่วมตามชื่อเล่นให้ · บอกเวลาและวางลิงก์ประชุมในประโยคได้ด้วย เช่น “21 ต.ค. บ่ายโมงครึ่ง ประชุมระบบบัญชี กับเกียง https://zoom.us/j/…” ระบบเติมเวลาและลิงก์ให้ · มีแถบสรุปว่าเติมอะไรไปบ้าง ชื่อที่หาไม่เจอจะแจ้งไว้ให้เลือกเอง · กด ↩ คืนข้อความเดิม เพื่อเอาประโยคเดิมกลับมา · ตรวจแล้วกด Enter อีกครั้งเพื่อบันทึก · ต้องการบันทึกทันทีโดยไม่ผ่าน AI กด Ctrl+Enter · แตะงานใน ล่าสุด: แล้วกด Enter = บันทึกเลย
  • หมวดงานแนะนำ — พิมพ์ชื่องานแล้วระบบเลือกหมวดให้จากงานเก่าที่ชื่อคล้ายกัน (ป้าย แนะนำ) · แตะหมวดเองเมื่อไร ระบบจะไม่เปลี่ยนให้อีก
  • ผู้เข้าร่วมแนะนำ — แถว แนะนำ: ใต้ช่องค้นหารายชื่อ แสดงคนที่มักไปงานลักษณะเดียวกันหรือไปกับคุณบ่อย แตะเพื่อเพิ่มได้ทันที
  • ✨ เรียบเรียง (ข้างหัวข้อรายละเอียด) — จดสั้น ๆ แล้วให้ AI เขียนเป็นข้อความทางการเป็นข้อ ๆ · กด ↩ ย้อนกลับ เพื่อใช้ข้อความเดิม
🔔 เตือนก่อนเริ่ม (มีเสียงอ่าน) — แสดงเมื่อใส่เวลาเริ่ม
  • ค่าเริ่มต้นเตือนก่อน 1 วัน และ 1 ชม. · กด ✕ บนป้ายเพื่อลบรอบ · กดปุ่มลัด + 1 วัน + 3 ชม. + 1 ชม. + 30 นาที หรือ ตั้งเอง: ใส่ตัวเลข เลือก วัน / ชม. / นาที แล้วกด + เพิ่ม (ไม่เกิน 5 รอบ ล่วงหน้าได้ไม่เกิน 14 วัน) · ติ๊ก ไม่ต้องเตือน ได้ · กด ↩ ใช้ค่าเริ่มต้น เพื่อกลับไปใช้ค่าของระบบ
  • ระบบเตือน ผู้เข้าร่วมทุกคน (ไม่เลือกผู้เข้าร่วม = เตือนผู้บันทึก) · แก้วันหรือเวลาประชุมแล้ว ระบบคำนวณเวลาเตือนใหม่ให้เอง · บันทึกตอนที่เลยรอบเตือนไปแล้ว รอบนั้นจะข้ามไป ไม่เตือนย้อนหลัง
  • เปิดหน้าเว็บอยู่ (แม้อยู่คนละแท็บ) — มีเสียง “ติ๊ง” แล้ว AI อ่านออกเสียง เช่น “แจ้งเตือนประชุมค่ะ อีกหนึ่งชั่วโมง จะถึงเวลาประชุม เรื่อง …” พร้อมกล่องเตือนกลางจอ มีปุ่ม 🎥 เข้าร่วม Zoom 🔁 ฟังอีกครั้ง ⏰ เตือนอีก 5 นาที 📝 ดูบันทึก

  • ตั้งค่าเสียงของเครื่องนี้ — กระดิ่ง › หัวข้อ ⏰ เตือนก่อนประชุม กดสลับ เสียงอ่าน: ทุกรอบ / เฉพาะก่อนเริ่ม ≤ 1 ชม. / ปิด · กด 🎧 ทดสอบเสียงเตือน เพื่อลองฟัง (ช่วยให้เบราว์เซอร์อนุญาตเล่นเสียงไว้ล่วงหน้าด้วย) · ถ้าขึ้น “แตะที่ใดก็ได้เพื่อฟังเสียงเตือน” ให้แตะหน้าจอหนึ่งครั้ง

  • มุมมองอื่น: 💬 ลูกค้าตอบกลับ, 👤 ยังไม่มอบหมาย, 🛠 กำลังทำ, ⏸ รอผู้แจ้ง, ✅ แก้แล้ว รอปิด, 📦 ปิด/ยกเลิก
  • คอลัมน์ “รอใคร”: ⏳ รอทีม · ⏸ รอผู้แจ้ง · 💬 ลูกค้าตอบ รอเราตอบ
  • กด รับงาน เพื่อรับเรื่องที่ยังไม่มีเจ้าของ หรือ 🤖 AI จัดคนให้ ให้ AI แนะนำผู้รับผิดชอบทั้งหมด

ตอบลูกค้าใน Ticket

  1. กด Ticket ในคิวเพื่อเปิด ดูรายละเอียดและไทม์ไลน์บทสนทนา (อัปเดตทันทีเมื่อลูกค้าตอบ)
  2. พิมพ์ข้อความ แนบไฟล์ด้วย 📎 ลากวาง หรือวางรูปด้วย Ctrl+V กด 🤖 ร่างข้อความตอบ ให้ AI ช่วยร่างได้
  3. ติ๊ก 🔒 โน้ตภายใน ถ้าเป็นข้อความถึงทีม (ลูกค้าไม่เห็น)
  4. กด ส่ง ➤ (Enter ส่ง, Shift+Enter ขึ้นบรรทัดใหม่) หรือใช้ปุ่มลัด ⏳ ส่ง แล้วรอผู้แจ้งตอบ / ✅ ส่ง แล้วแจ้งว่าแก้ไขเสร็จ
  5. ปรับสถานะ Priority ผู้รับผิดชอบ และหมวดได้ที่การ์ด “ข้อมูล Ticket” ด้านขวา แล้วกด 🔒 ปิดงาน เมื่อจบ
  6. เมื่อแก้ไขเสร็จ ระบบจะชวนบันทึก สาเหตุ และ วิธีแก้ไข เข้าคลังความรู้ (AI เติมร่างให้) ลูกค้าจะเห็นวิธีแก้นี้ในหน้าติดตาม

แจ้งแทนลูกค้า

  • + แจ้งแทน — กรอกโรงพยาบาล ระบบที่ใช้ ชื่อผู้แจ้ง รายละเอียด และความเร่งด่วน AI จะจัดหมวด Priority และผู้รับผิดชอบให้
  • 🤖 วางแชท LINE — ลากไฟล์แชท .txt ได้หลายไฟล์พร้อมกัน (หลายกลุ่ม/หลายโรงพยาบาล) และ/หรือวางข้อความแชท เลือกช่วงแชท ด้วยปุ่ม วันนี้ / 7 วันล่าสุด / 30 วัน / ทั้งหมด / กำหนดเอง แล้วกด 🤖 ให้ AI แยกเรื่อง (เรื่องที่แก้จบในแชทแล้วจะถูกบันทึกเป็นปิดงาน)
    ก่อนนำเข้า: แต่ละไฟล์เป็น 1 แถว บอกจำนวนข้อความในช่วง ปุ่ม 👁 ดูแชท และโรงพยาบาลที่ระบบจับคู่ให้พร้อมเหตุผล (เคยใช้กับกลุ่มนี้ / ตรงรหัส / ตรงชื่อกลุ่ม / ผู้ส่งในแชทตรงกับผู้ติดต่อของโรงพยาบาล) กด เปลี่ยน เพื่อเลือกเองหรือแก้ชื่อกลุ่ม LINE · ถ้าไม่ทราบหรือตรงหลายแห่ง ระบบจะไม่เดา แต่ขึ้นปุ่มโรงพยาบาลที่ใกล้เคียงให้กดเลือกก่อน
    AI หาระบบที่ใช้งาน (ดูระบบที่โรงพยาบาลนั้นใช้ก่อน ถ้าโรงพยาบาลใช้ระบบเดียวจะใช้ระบบนั้น) หมวด ผู้แจ้ง (จับคู่กับผู้ติดต่อของโรงพยาบาล ได้ชื่อเต็ม/เบอร์/ตำแหน่ง) และผู้รับผิดชอบ · ค่าที่ไม่แน่ใจจะเว้นว่างให้เลือก
    หน้าตรวจทาน: แถบซ้ายเป็นรายชื่อโรงพยาบาล บอกจำนวนเรื่องและ "ไม่ครบ N เรื่อง" — กดแล้วเห็นเรื่องของโรงพยาบาลนั้นทันที · แถวบนกรองสถานะ ทั้งหมด ข้อมูลไม่ครบ อาจซ้ำ รอดำเนินการ แก้แล้วในแชท · แต่ละโรงพยาบาลเป็นกล่อง เลือก/ไม่เลือกทั้งโรงพยาบาลได้ พับเก็บได้
    เรื่องที่ข้อมูลไม่ครบมีแถบแดงและป้าย "ยังขาด: …" เลือกช่องที่ขาด (ระบบ / หมวด / ผู้รับผิดชอบ / โรงพยาบาล) ในการ์ดได้เลย ติ๊ก ใช้กับเรื่องอื่นในกลุ่มนี้ที่ยังว่าง เพื่อเติมให้เรื่องอื่นของโรงพยาบาลเดียวกันพร้อมกัน (ไม่ทับค่าที่มีแล้ว) · เรื่องที่อาจซ้ำกับ Ticket เดิมจะไม่ถูกเลือกไว้ กด ไม่ซ้ำ สร้างด้วย ถ้าต้องการ · กดที่เรื่องเพื่อกางแก้ไขทุกช่องพร้อมแชทต้นทาง (ตัวหนา = ข้อความที่ AI ใช้สรุป) · สลับสถานะ รอดำเนินการ / แก้แล้วในแชท ได้ในแถว
    ท้ายหน้าต่างสรุปจำนวนที่จะสร้างแยกตามโรงพยาบาล กด 💾 สร้าง N Ticket ได้ทันที (ถ้ายังมีเรื่องไม่ครบ ระบบพาไปที่ตัวกรอง "ข้อมูลไม่ครบ")
  • 🔗 ลิงก์ฟอร์มแจ้งเอง — ลิงก์และ QR Code ของฟอร์มแจ้งปัญหา สำหรับพิมพ์ติดที่โรงพยาบาล

ตรวจไฟล์ Excel/CSV ข้อมูลพื้นฐาน (เช่น ระบบคลังสินค้า) ก่อนนำเข้าระบบ แทนการนั่งไล่ดูทีละแถว — หาอักขระพิเศษที่มองด้วยตาไม่เห็น, ข้อมูลซ้ำ, ช่องที่ว่าง, ค่าที่ไม่ใช่ตัวเลข และชื่อที่คล้ายกัน แล้วแก้อักขระให้อัตโนมัติ ไฟล์ตรวจในเครื่องของผู้ใช้ ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

  1. ลากไฟล์มาวาง หรือกดเลือกไฟล์ (.xlsx .xls .csv — CSV ภาษาไทยแบบ TIS-620 ระบบแปลงให้เอง)
  2. ① ยืนยันคอลัมน์ — แต่ละคอลัมน์มีปุ่มเลือกว่าเป็น รหัส (ห้ามซ้ำ ห้ามเว้นวรรค) · ชื่อ (หาชื่อคล้าย) · ตัวเลือก (เช่น หน่วยนับ ประเภท) · ตัวเลข · ข้อความทั่วไป · ไม่ตรวจ และติ๊ก ห้ามว่าง — ระบบเดาจากหัวคอลัมน์ให้แล้ว ดูแค่ว่าถูกไหม (แถวที่เปลี่ยนจากที่ระบบเดาเป็นสีส้ม) · ชีต/แถวหัวตาราง/อักขระต้องห้าม (ค่าเริ่มต้น ' " \ |)/ความคล้ายของชื่อ อยู่ใน ตัวเลือกเพิ่มเติม แล้วกด เริ่มตรวจ
    ถ้าเลือกผิด เช่น ตั้งคอลัมน์ชื่อยาเป็น “รหัส” ระบบจะเตือน “รหัสมีเว้นวรรค” เป็นร้อยช่องทั้งที่ไม่ใช่ปัญหา
  3. ② ตัดสินปัญหาทีละกลุ่ม — ด้านบนบอก เหลือต้องตัดสินกี่ช่อง พร้อมแถบความคืบหน้า · ด้านซ้ายแยกกลุ่มตามปัญหา + คอลัมน์ (เช่น รหัสมีเว้นวรรค · ช่องที่ห้ามว่าง · มีอักขระต้องห้าม) พร้อมจำนวนที่เหลือ เรียงกลุ่มใหญ่ก่อน กดกลุ่มเพื่อดูรายการ:
    • ทั้งกลุ่มในคลิกเดียว — ✨ ให้ AI ช่วยดูทั้งกลุ่ม (AI ดูแต่ละช่องพร้อมข้อมูลอื่นในแถว ครั้งละสูงสุด 600 ช่อง) → ✔ ใช้ผล AI ทั้งกลุ่ม (ช่องที่ AI แนะนำแก้ใช้ค่าใหม่ · ช่องที่ AI ว่าไม่ต้องแก้คงค่าเดิม · ช่องที่ AI ตัดสินไม่ได้เหลือให้คนดู) หรือ ไม่ใช่ปัญหา — ข้ามทั้งกลุ่ม
    • 💡 ต้นเหตุที่เป็นไปได้ — กลุ่มปัญหารหัสมีปุ่ม ตั้งเป็นคอลัมน์ “ชื่อ” แล้วตรวจใหม่ · กลุ่มช่องห้ามว่างมีปุ่ม ตั้งเป็น “ว่างได้” แล้วตรวจใหม่ — ช่องที่ตัดสินไปแล้วในกลุ่มอื่นยังอยู่
    • ทีละช่อง — แต่ละแถวบอกเลขแถว รหัส/ชื่อของรายการ ค่าในไฟล์ (จุดที่ผิดไฮไลต์แดง เว้นวรรคแสดงเป็น ␣) และผล AI · กด ✔ ใช้ค่านี้ (ค่าที่ AI แนะนำ) หรือพิมพ์ค่าเองแล้ว บันทึกค่าที่พิมพ์ (Enter ได้) หรือ ไม่ต้องแก้ · ปุ่มที่ AI แนะนำเป็นสีม่วง · กด เปลี่ยนใจ เพื่อยกเลิก
    • กลุ่มที่เสร็จมีเครื่องหมาย ✓ และปุ่ม ไปกลุ่มถัดไป
    • ตรวจเพิ่มเติม (ไม่บังคับ) — ข้อมูลซ้ำ (รวมซ้ำแบบมองไม่เห็นที่ต่างกันแค่เว้นวรรค/อักขระแฝง) และ ชื่อคล้ายกัน กด ✨ ให้ AI ตรวจ ให้ AI ช่วยดูว่าเป็นรายการเดียวกันไหม
    • ระบบแก้ให้อัตโนมัติ — ค่าเดิม → ค่าใหม่ พร้อมสิ่งที่แก้ ไม่ต้องกดอะไร (กด ✨ ให้ AI ตรวจทาน ได้ถ้าอยากแน่ใจ)
  4. ③ ดาวน์โหลด — กด ⬇️ ดาวน์โหลดไฟล์ที่แก้แล้ว (ได้ทุกเมื่อ ไม่ต้องตัดสินครบ) — ในไฟล์ ช่องที่แก้/มีปัญหา/ซ้ำ มี Comment (สามเหลี่ยมแดงมุมช่อง ชี้เมาส์เพื่ออ่าน) บอกค่าเดิมและเหตุผล · ชีต ผลตรวจ สรุปทุกจุดเรียงตามแถว (✅ ระบบแก้ · 🤖 AI แก้ · ✏️ แก้เอง · ✔ ไม่ต้องแก้ · ✋ ยังต้องแก้) กรองตามสถานะได้ · ชีตอื่นในไฟล์คงเดิม
  5. กด 🧩 คอลัมน์ ที่แถบไฟล์ เพื่อกลับไปแก้ขั้นยืนยันคอลัมน์ได้ตลอด

รายชื่อ รพ.

เมนู ข้อมูลอ้างอิง › รายชื่อ รพ.

ฐานข้อมูลโรงพยาบาล ค้นหาด้วยรหัส/ชื่อ/อำเภอ และกรองตามจังหวัด อำเภอ ระดับ Product ที่ใช้ ส่งออก Excel ได้

  • หัวหน้า แบ่ง 2 แถว — แถวบน: แท็บมุมมอง (ซ้าย) · จำนวน รพ. ที่พบ + ปุ่ม เครื่องมือ Excel เพิ่ม รพ. (ขวา) · แถวล่าง: ช่องค้นหาและตัวกรองทั้งหมด — เมื่อกรองอยู่จะมีปุ่ม ล้างตัวกรอง คืนค่าทุกช่องในคลิกเดียว
  • แท็บ: รายชื่อ รพ. · สรุปข้อมูลการติดต่อ · วิเคราะห์ Product (อัตราการใช้ Product และโอกาสขายเพิ่ม) · Dashboard
  • กดชื่อ รพ. เพื่อดู ข้อมูลทั่วไป, ผู้ติดต่อ, ระบบ/Anydesk (รหัสผ่านเก็บแบบเข้ารหัส ซ่อนไว้ — กด 👁 ระบบจึงโหลดรหัสมาแสดง และบันทึกว่าใครเปิดดูเมื่อไร) และ Product ที่ใช้
  • ผู้ดูแลเพิ่ม รพ. ด้วย เพิ่ม รพ. — พิมพ์ HOS Code แล้วระบบดึงข้อมูลจาก MOPH ให้ หรือ เครื่องมือ › เติมข้อมูลจาก API เติมช่องที่ว่าง (ไม่ทับข้อมูลเดิม)
  • พิกัด รพ. (ใช้วางหมุดบนแผนที่ทีม) — ผู้ดูแลกด เครื่องมือ › เติมพิกัด รพ. ระบบจับคู่ชื่อ + จังหวัด + อำเภอ กับข้อมูลพิกัดสถานพยาบาลของรัฐ (กระทรวงสาธารณสุข · data.go.th) แล้วแสดงผลแยกเป็น ตรงชัด · ต้องเลือก · ไม่พบ (ส่วนใหญ่เป็น รพ. เอกชน) — ระบบติ๊กไว้ให้แล้วทั้งที่ตรงชัดและที่ต้องเลือกซึ่งคะแนน 80% ขึ้นไป หรือกด เลือกอันดับแรกทุกแถว → กด 📍 บันทึกพิกัด ครั้งเดียวบันทึกทั้งหมด · เติมเฉพาะ รพ. ที่ยังไม่มีพิกัด
  • ดูว่า รพ. ไหนมีพิกัดแล้ว — การ์ด รพ. แสดงป้าย 📍 มีพิกัด (กดเปิด Google Maps) หรือ ไม่มีพิกัด · กรองด้วยช่อง ทุกสถานะพิกัด → มีพิกัดแล้ว / ยังไม่มีพิกัด · เพิ่ม รพ. ใหม่โดยไม่กรอกพิกัด ระบบหาจากข้อมูล สธ. ให้อัตโนมัติถ้าชื่อตรงชัด
  • กรอกพิกัดเองในหน้าแก้ไข รพ. ช่อง พิกัด — วางตัวเลข ละติจูด, ลองจิจูด (ใน Google Maps คลิกขวาที่ รพ. แล้วคลิกตัวเลขพิกัดเพื่อคัดลอก) หรือวางลิงก์ Google Maps แบบเต็ม · กด ค้นจาก สธ. ให้ระบบหาให้ · กด ดูแผนที่ ตรวจว่าตรงจุด · ลิงก์ย่อ (maps.app.goo.gl) อ่านพิกัดไม่ได้ · รพ. ที่ยังไม่มีพิกัด แผนที่จะวางหมุดไว้กลางจังหวัด
  • แก้ไข รพ. แท็บ ระบบ/Anydesk — ช่องรหัสผ่านที่มีรหัสอยู่แล้วแสดง •••••••• (กด 👁 เพื่อดู) ไม่ต้องกรอกใหม่ บันทึกแล้วรหัสเดิมยังอยู่ · จะเปลี่ยนรหัสให้พิมพ์ทับ · จะลบรหัสให้กด 👁 แล้วลบข้อความในช่องก่อนบันทึก

ข้อมูลสัญญา

เมนู ข้อมูลอ้างอิง › ข้อมูลสัญญา

ทะเบียนสัญญาจัดกลุ่มตามลูกค้า พร้อมมูลค่าและความคืบหน้าการเรียกเก็บเงิน การ์ดสรุป: สัญญาทั้งหมด, มีผลบังคับ, มูลค่ารวม, ใกล้หมดอายุ (30 วัน), ปิดแล้ว/ยังต้องเรียกเก็บ

เพิ่มสัญญา (ผู้มีสิทธิ์เพิ่มสัญญา)

  1. กด เพิ่มสัญญา — รหัสสัญญาสร้างอัตโนมัติ (🔄 อัตโนมัติ)
  2. กรอกชื่อโครงการ, ลูกค้า/คู่สัญญา, มูลค่า, วันลงนาม, วันเริ่ม-สิ้นสุด (หรือกรอกระยะสัญญาเป็นเดือน/ปี ให้คำนวณวันสิ้นสุด)
  3. เพิ่มรายการรับเงินเองได้ที่ ＋ เพิ่ม Transaction แล้วกด 💾 บันทึก

การเรียกเก็บ: โครงการที่ผูกกับสัญญาและปิดแล้ว นับเป็น “ปิดแล้ว” · ที่ยังดำเนินการอยู่นับเป็น “ค้างเก็บ” (ผูกโครงการกับสัญญาได้ที่ช่อง 🔗 ผูกสัญญา ในหน้าโครงการ) สถานะสัญญา: ✅ มีผลบังคับ · 🏁 สิ้นสุดแล้ว · 🚫 ยกเลิก

🔑 ผู้ใช้งานระบบสร้างบัญชี ตั้ง/รีเซ็ตรหัสผ่าน กำหนดกลุ่มสิทธิ์ (ได้หลายกลุ่ม) และผูกกับพนักงาน — รายชื่อแบ่งหัวข้อตามกลุ่มสิทธิ์ (ผู้ใช้หลายกลุ่มแสดงในทุกกลุ่มที่สังกัด) พร้อมคอลัมน์ ผูกกับพนักงาน — บัญชีที่ยังไม่ผูกจะขึ้นป้าย “ยังไม่ผูก”
🔐 สิทธิ์การใช้งานสร้าง/คัดลอก/ลบกลุ่มสิทธิ์ ตั้งสิทธิ์ ดู/เพิ่ม/แก้/ลบ/อนุมัติ รายเมนู ขอบเขตข้อมูล และหน้าแรกหลัง Login ของแต่ละกลุ่ม

สร้างบัญชีผู้ใช้ใหม่

  1. เพิ่มพนักงานที่ 👥 พนักงาน (ถ้ายังไม่มี)
  2. ไปที่ 🔑 ผู้ใช้งานระบบ › + เพิ่มบัญชีผู้ใช้ กรอก Username, Password, ชื่อ และติ๊ก กลุ่มสิทธิ์ (ได้หลายกลุ่ม — ใต้ช่องจะสรุปเมนูที่ผู้ใช้จะเห็น)
  3. เลือก ผูกกับพนักงาน — จำเป็นสำหรับกลุ่มที่มีขอบเขต “ของตัวเอง/ทั้งแผนก” เช่น การลางาน (ไม่ผูก = ไม่เห็นใบลาของใคร) · ระบบ 🤖 จับคู่ให้อัตโนมัติ ระหว่างพิมพ์ชื่อที่แสดง/Username โดยเทียบกับชื่อ-นามสกุล ชื่อเล่น และ Email ของพนักงาน — ถ้าใกล้เคียงหลายคนจะแสดงปุ่มให้กดเลือก ตรวจดูแล้วเปลี่ยนเองได้เสมอ
  4. บันทึก แล้วแจ้ง Username และรหัสตั้งต้น 123456 (ใส่ให้อัตโนมัติ) ให้ผู้ใช้ — เข้าระบบครั้งแรกระบบจะบังคับให้ตั้งรหัสของตัวเอง

รีเซ็ตรหัสผ่าน

คำขอจะขึ้นที่กระดิ่ง และมีป้าย 🔑 ขอรีเซ็ตรหัสผ่าน ในรายชื่อผู้ใช้ กด ✏️ ช่องรหัสผ่านจะมี 123456 ใส่ไว้ให้แล้ว กดบันทึก (คำขอจะหายเอง) แล้วแจ้งผู้ใช้ว่าเข้าด้วย 123456 และตั้งรหัสใหม่ตอนเข้าระบบ · ผู้ใช้ที่ไม่ได้ส่งคำขอ กด ✏️ แล้วกดปุ่ม 🔄 รีเซ็ตเป็น 123456 ใต้ช่องรหัสผ่าน

จัดการกลุ่มสิทธิ์

  1. ไปที่ 🔐 สิทธิ์การใช้งาน — ด้านซ้ายคือรายชื่อกลุ่มพร้อมจำนวนผู้ใช้ กดกลุ่มเพื่อแก้ไข หรือกด + เพิ่มกลุ่มสิทธิ์
  2. ตั้งชื่อ สี หน้าแรกหลัง Login และลำดับ (ผู้ใช้หลายกลุ่ม: กลุ่มลำดับน้อยกว่ากำหนดหน้าแรก)
  3. ติ๊กสิทธิ์รายเมนู — ติ๊ก เพิ่ม/แก้/ลบ/อนุมัติ ระบบจะติ๊ก “ดู” ให้เอง เอา “ดู” ออกจะล้างทั้งแถว กดหัวคอลัมน์ ชื่อหมวด หรือชื่อเมนู เพื่อเปิด/ปิดทั้งชุด
  4. เมนูที่มีขอบเขตข้อมูล (เช่น การลางาน) เลือก ของตัวเอง / ทั้งแผนก / ทั้งหมด
  5. กด 💾 บันทึก — ผู้ใช้ในกลุ่มเห็นผลทันทีไม่ต้อง Login ใหม่

สร้างกลุ่มที่คล้ายของเดิมได้เร็วด้วย ⧉ คัดลอกเป็นกลุ่มใหม่ · ลบกลุ่มได้เมื่อไม่มีผู้ใช้เหลืออยู่ในกลุ่ม · กลุ่ม Admin แก้สิทธิ์ไม่ได้ (เต็มเสมอ) และระบบไม่ให้ลบ/ถอด Admin คนสุดท้าย

นำเข้าข้อมูล ผู้ดูแลระบบ

ปุ่ม “นำเข้า” บนแถบด้านบน

นำเข้าข้อมูลจำนวนมากจากไฟล์: โครงการ, พนักงาน, ผู้ใช้งาน, รายการเบิกจ่าย, กลุ่ม/ประเภท/ตำแหน่ง/แผนก, สัญญา, รายชื่อโรงพยาบาล ผู้ติดต่อ และ Product (Excel), ปัญหาเก่า HelpDesk, ปัญหาการใช้งานเก่า (Impl Tracker — 1 ไฟล์ต่อ 1 โครงการ) และคำขอทีม Server

  1. เลือกชนิดข้อมูล (ระบบเลือกให้ตามหน้าที่เปิดอยู่ เช่น อยู่หน้า Admin › พนักงาน จะเลือก “พนักงาน” ไว้แล้ว เปลี่ยนเองได้) แล้วกด ⬇ ดาวน์โหลดไฟล์ตัวอย่าง เพื่อดูรูปแบบคอลัมน์
  2. กรอกข้อมูลตามตัวอย่าง แล้วลากไฟล์มาวาง/คลิกเลือกไฟล์ (ผู้ใช้งาน: คอลัมน์ roles ใส่ชื่อกลุ่มสิทธิ์ หลายกลุ่มคั่นด้วย | เช่น ผู้จัดการ|หัวหน้าทีม)
  3. ตรวจตัวอย่างก่อนนำเข้า (ถ้ามี) แล้วกด 🚀 นำเข้าข้อมูล — อย่าปิดหน้าจนกว่าจะเสร็จ
ตัวเลือก ⚠ ลบข้อมูลเดิมก่อนนำเข้า จะลบข้อมูลชนิดนั้นทั้งหมดก่อนนำเข้า ใช้เฉพาะเมื่อแน่ใจ

ฟอร์มแจ้งปัญหา (help.html)

คัดลอกลิงก์จาก Helpdesk › 🔗 ลิงก์ฟอร์มแจ้งเอง

  1. ลูกค้าเลือกโรงพยาบาล กรอกชื่อ เบอร์/LINE เลือกระบบที่ใช้ ความเร่งด่วน รายละเอียด และแนบรูปหน้าจอ แล้วกด ส่งเรื่อง
  2. ได้เลขที่ Ticket และ ลิงก์ติดตาม — ควรบันทึกลิงก์นี้ไว้
  3. ในหน้าติดตาม ลูกค้าเห็นความคืบหน้า แชทกับทีมงาน แนบไฟล์ และเห็นว่าทีม “อ่านแล้ว” หรือยัง
  4. เมื่อแก้ไขเสร็จ ลูกค้าเห็นสรุปวิธีแก้ ให้คะแนน 1–5 ดาว หรือกด ↺ ยังไม่หาย เปิดเรื่องใหม่

เรื่องที่เลือก “ทำงานไม่ได้เลย” ลูกค้ากด 📞 เริ่มคุยสดกับทีมงาน เพื่อวิดีโอคอลได้ ลิงก์ติดตามหมดอายุหลังปิดเรื่อง 30 วัน

ฟอร์มขอใช้งานทีม Server (server-request.html)

คัดลอกลิงก์จากเมนูขอใช้งานทีม Server › คัดลอกลิงก์ฟอร์มขอ ผู้ขอกรอก 4 ขั้น: ผู้ขอ → โรงพยาบาลและ IT ผู้ติดต่อ → รายละเอียดงาน → ช่วงวันที่และจำนวนคน (ปฏิทินแสดงวันว่างของทีมแบบเรียลไทม์) จากนั้นได้ลิงก์ติดตามสถานะการอนุมัติ และยกเลิกคำขอได้ระหว่างรออนุมัติ

หน้าอบรม (ลงทะเบียน / แบบประเมิน / แบบทดสอบ)

  • ลงทะเบียน — เลือกหลักสูตร → รอบอบรม → กรอกข้อมูล รับ QR Code สำหรับเช็คชื่อ ดู/แก้ไข/ยกเลิกการลงทะเบียนได้ภายหลัง
  • แบบประเมิน — เปิดได้เฉพาะวันที่มีรอบอบรม ให้คะแนน 1–5 แล้วกด ส่งแบบประเมิน
  • แบบทดสอบ — ระบุตัวตนและอีเมล ทำข้อสอบ ดูผลทันที ผู้ที่สอบผ่านได้รับใบประกาศทางอีเมล

คำถามที่พบบ่อย & แก้ปัญหาเบื้องต้น

ไม่เห็นเมนู / ปุ่มที่ต้องใช้

กลุ่มสิทธิ์ของคุณยังไม่มีสิทธิ์ในเมนูนั้น ติดต่อผู้ดูแลระบบให้เพิ่มสิทธิ์ให้กลุ่ม หรือเพิ่มคุณเข้ากลุ่มที่มีสิทธิ์ (Admin Panel › สิทธิ์การใช้งาน / ผู้ใช้งานระบบ)

ข้อมูลไม่อัปเดต หรือหน้าจอแสดงผิดปกติ

กดรีเฟรช (F5) ถ้ายังไม่หาย ให้ออกจากระบบแล้วเข้าใหม่ หรือกด Ctrl+Shift+R เพื่อโหลดเวอร์ชันล่าสุด

ขึ้นหน้าแจ้งปัญหาฐานข้อมูล (เชื่อมต่อไม่ได้ / โครงสร้างยังไม่อัปเดต / ไม่มีสิทธิ์)

หน้าจอจะบอกสาเหตุและวิธีแก้ทีละขั้นตามประเภทปัญหา ทำตามขั้นตอนแล้วกด ลองใหม่ ถ้ายังไม่หาย กด คัดลอกข้อผิดพลาด แล้วส่งให้ผู้ดูแลระบบ (กด “รายละเอียดทางเทคนิค” เพื่อดูข้อความเต็ม)

ไม่มีชื่อพนักงานในรายชื่อทีม/ลางาน

พนักงานอาจยังไม่ถูกเพิ่ม หรือสถานะเป็น Inactive ให้ผู้ดูแลตรวจที่ Admin Panel › พนักงาน

แก้ไขใบลาที่อนุมัติแล้วไม่ได้

ใบลาที่อนุมัติแล้วจะถูกล็อก ต้องให้ Admin แก้ไขหรือลบให้

ลบโครงการไม่ได้

โครงการที่มี Advance หรือข้อมูลที่พักแล้วลบไม่ได้ ต้องลบรายการเหล่านั้นก่อน หรือเปลี่ยนสถานะเป็นยกเลิกแทน

ค่าใช้จ่ายไม่ขึ้นในหน้างบประมาณ

รายการค่าใช้จ่ายจะเข้าหน้างบประมาณเมื่อใบ Advance ถูกบันทึกเป็น เคลียร์แล้ว เท่านั้น

พิมพ์เอกสารแล้วไม่มีอะไรขึ้น

เบราว์เซอร์อาจบล็อกหน้าต่าง Popup ให้กดอนุญาต Popup สำหรับเว็บนี้ แล้วลองใหม่
